星之骰戏 (Astral Dice) 1.5.0 玩家更新日志

已发布：1.5.0（正式版）—— 覆盖自 1.3.7 以来的全部改动，并在 1.5.0-rc.7 之后完成定版。本次是四条平台线（NeoForge 1.21.1 / Forge 1.20.1 / NeoForge 26.1.2 / Fabric 1.20.1）同时正式发布，四个 jar 同属一个 Release。主要变化：

  • 商店体系：方块「卡牌商店」与「筹码商店」、村民职业「卡牌交易员」与「筹码商人」、方块「抽奖盒」；
  • 事件体系：12 个事件 + 事件卡动画 + 大侦探的「事件选择界面」；
  • 内容：7 张新立牌（超天酱 / 地雷女 / 修女 / 大肥鱼 / 多萝西 / 调酒师 / 怪力乱神；立牌总数 24 → 31）、
    两张新效果牌（路障 / 强化拒止，后者另有物品形态）、6 枚新筹码（筹码池 61 → 67）；
  • 平衡：10 张既有立牌、16 枚既有筹码与诡异骰子有机制 / 数值调整；两处「获得即触发」的口径统一（去掉「合成」）；村民交易价格重定（筹码 20-64、卡牌 5-20），绿宝石骰子改为 1:1 折算；
  • 战斗系统重做：防御公式按玩家 / 生物分离、防御力 1:1 折算、生物攻击纳入骰战、伤害下限改为攻击力的 15%、战斗牌改为单次递减掷骰、防御牌耐久 150、原版伤害修饰器回归、伤害跳字按类型分色；
  • 界面：战斗数值条（防御力条 / 攻击力条）、Jade 联动、商店冷却倒计时；
  • 许可：源代码改为 GPL-3.0-only。
  • 修复：法伤加成的重复结算、1.20.1 的护盾 / 黄心口径、事件牌惩罚伤害等一批战斗与结算问题；筹码手册条目改为「获取途径」说明；事件动画期间大侦探技能卡死与 ESC 无法取消已修。

本版同时发布四个构建：astral_dice-1.5.0+neoforge_1.21.1.jar（Minecraft 1.21.1 / NeoForge）、astral_dice-1.5.0+forge_1.20.1.jar（Minecraft 1.20.1 / Forge）、
astral_dice-1.5.0+neoforge_26.1.2.jar（Minecraft 26.1.2 / NeoForge）与 astral_dice-1.5.0+fabric_1.20.1.jar（Minecraft 1.20.1 / Fabric）。四条线同属一个 Release，tag 为 1.5.0。

本版（1.5.0 正式版）相对 1.5.0-rc.7 的改动

定版前的工作集中在四件事上：修掉一个必现崩服、把筹码「深渊试剂」的名称在四条线统一、补齐两条线各自的零星缺口。下文各章节是自 1.3.7 以来的全量内容，本节只列 rc.7 之后新增的部分。

  • 修复一个必现崩服：生物属性表里没有 attack_damage 时，它的近战命中玩家会让服务端整段崩溃（日志表现为 Ticking entity）。四条线现在都先判该属性是否存在，缺失时按 0 处理，不再崩。
  • 筹码「深渊试剂」名称统一：物品显示名、提示框、图鉴与手册条目里的引用全部对齐，英 / 日分别为 Abyss Reagent / 深淵試薬。
  • Fabric 1.20.1 补齐 6 张立牌的配方书解锁条目（alana / ame / dorothy / jill / kangel / lingling）：此前这 6 张立牌在配方书里查不到，只能在 JEI 与手册里看到，现在配方书里能查到。
  • Fabric 1.20.1 修正 misaki 立牌的配方材料：材料由 golden_star_plate 更正为 star_plate，与另外三条线一致。
  • NeoForge 26.1.2 创造栏补齐 2 张蛟龙立牌专属战斗牌（「撕咬」attack_card_bite 与「龙之咆哮」attack_card_dragon_roar）：此前这两张牌只能由蛟龙立牌的技能发放，创造栏里没有条目。

安装与前置（必读）

  • 本版起 StarEngine 不再内嵌（四条线全部适用）：四个发货 jar 里都已删除内嵌库 —— NeoForge 26.1.2 的
    jarJar 与 Fabric 1.20.1 的 Loom include 一并撤除，jar 内不再含 META-INF/jarjar/ 或 META-INF/jars/，
    StarEngine（modId starengine，1.1.0）在四条线上都改为独立前置。请按自己那条线下装一个库 jar 放进 mods：
    NeoForge 1.21.1 用 starengine-neoforge-1.21.1-1.1.0.jar、Forge 1.20.1 用 starengine-forge-1.20.1-1.1.0.jar、
    NeoForge 26.1.2 用 starengine-neoforge-26.1.2-1.1.0.jar、Fabric 1.20.1 用 starengine-fabric-1.20.1-1.1.0.jar
    （下载源：CurseForge 的 StarEngine 项目，id 1755415）。一直用旧版内嵌库的玩家不用做任何事 —— 旧版本自带库、
    照旧能进游戏；从 1.5.0 起才必须把库 jar 单独放进 mods。版本区间：NeoForge 两线 [1.1.0,2.0.0)、
    Fabric 线 >=1.1.0 <2.0.0（等价）；缺库或版本越界会以「Missing or unsupported mandatory dependencies」拒绝启动 ——
    看到这句话先检查库 jar 是否漏装、版本是否落在区间内。
  • 1.20.1 的 Mixin 运行时：Mixin Booster ≥0.1.3 或 Sinytra Connector，二选一即可。
  • 卡牌不再能合成：22 条卡牌合成配方已移除，卡牌改为通过卡牌商店 / 卡牌交易员 / 骰子与立牌等方式获得。
  • 1.3.7 及以前的存档可以直接升级；商店、事件、村民等新内容都是新增内容，不会改写旧存档里的物品。

新增内容

卡牌商店（新方块）

  • 合成：上排 3 个平滑石台阶、中排 3 枚星币、下排 3 个原木（3×3 工作台）。放下后右键打开，无消耗、无冷却。
  • 货架：基础上架 3 张卡牌（同一批不会出现两张同名卡），基础价 3 枚星币；
    每格买走后显示「已售出」；同一批卡持续有效，只有 60 秒轮询归零那一刻才换一批（关掉再开不刷新）。
  • 经商立牌联动：同队有人佩戴「经商立牌」时额外上架 1 张战斗牌，且每张牌各有 10% 概率降价为 1 枚星币。
  • 蓄力牌只有在骰子星级 ≥ 2 时才会出现在货架。
  • 界面：带玻璃展示窗的木质柜台（Blockbench 模型，碰撞与选中框随模型收紧）；品红标题「卡牌商店」居中；
    6 个卡框，卡面填满、卡名完整显示（过长自动缩字号）；折扣牌在卡面右下角标出；
    左侧按钮 = 星光兑换星币，中间按钮 = 转账（星币少于 5 枚或冷却中灰化），沙漏按冷却进度显示；
    左下为星币余额条，右下为玩家物品栏。
  • 购买改为「拖拽成交」：按住货架上的卡牌拖到右下物品栏才算购买 —— 拖动时卡牌跟随光标、原卡位显示「已售出」底图；
    没拖到物品栏就自动移回（不扣钱）；星币不足时拖不动（红字提示所需星币）；落点格被占用会提示换一格。
    空槽位统一显示「已售出」样式。
  • 购得即视为「获得」：会正常触发维生素药丸的治愈与教主立牌的狐光层数；购买成功播放钱包音效。
  • 界面细节：按钮改为纯图标（说明移到悬停提示）；转账页面完全独立（打开转账时商店内容一律不渲染）；
    转账金额为 4 档按钮（5 / 10 / 15 / 20），带玩家名搜索框、滚动列表、每行显示头像 + 名字 + 当前余额，
    选中行有粉色箭头指示；转账成功后自动退回商店主界面，同一轮内不能再次转账。

卡牌商店内的「星光兑换」与「转账」

  • 星光兑换：2 点星光 = 1 枚星币，无冷却，每轮一次（星光不足时给提示）。这是「经商立牌」原主动「套现」迁入商店后的入口。
  • 转账：把星币转给同服务器其他在线玩家，单次 5~20 枚，每次转账后 60 秒冷却（与商店换牌共用同一个计时器，掉线也照算）；
    目标在确认前离线会自动刷新名单并提示重选；每轮一次。
    佩戴「经商立牌」的玩家转账成功后，自己货架上顺序第一张未售出的卡牌会被强制降到 1 星币。

筹码商店（新方块）

  • 合成：金锭 · 星盘 · 金锭 / 磨制黑石砖块 · 空白筹码 · 磨制黑石砖块 / 磨制黑石砖块 ×3（3×3 有序）。
  • 一次给出 3 个筹码格，从你尚未拥有的筹码中按权重抽取（同一批不重复），每格显示该筹码自己的图标，三格同价。
  • 价格：从 10 枚星币起步，同一个玩家每买过一枚就 +5、上限 100（刷新或重开都不重置）。
  • 品质按骰子星级加权：0–1★ = 稀有 60% / 史诗 37% / 传奇 3%；2★ = 40% / 45% / 15%；3★ = 25% / 50% / 25%。
  • 流派权重：你已装备的同流派筹码会让该流派更容易被抽到（每枚 +60%）；上一次买下的类别在本批第一格权重 ×2（第二、三格 ×1.25）。
  • 刷新：初始 3 次、上限 5 次，用掉第一次刷新后才开始计时，每 30 分钟恢复 1 次（不在店里也照常累积）；
    次数用尽时刷新按钮只闪红、不再发包。已集齐全部筹码或物品栏没有空位时无法开店（会给提示）。
  • 购买：买下后筹码直接进物品栏并关闭界面；购买后商店进入 5:00 冷却；冷却中右键空白筹码可把它投入商店 ——
    立即解除冷却并 +1 次重抽，每 2:00 限一枚。物品栏满时照常成交：扣款、次数 +1、候选重抽都照常，
    装不下的那枚掉在脚边并提示；创造模式下按原版规则直接被吞掉（不掉落、无提示）。
  • 界面：花费栏 = 星币小图标 + 金额；刷新只显示剩余次数；候选图标 24×24；候选格脚下按品质画三色描边环（稀有蓝 / 史诗紫 / 传奇金）；
    过长筹码名左右滚动；被选中的格子名称改黑字；鼠标悬停候选筹码（筹码格或其下方标签都算命中）即弹 tooltip。
    商店不绘制标题；没有任何折扣路径（「会员推荐信」的减价只作用于卡牌商店）。

村民职业

  • 卡牌交易员（卡牌商店方块为工作方块）：新手 / 学徒上架稀有卡（2–6 绿宝石）、老手 / 专家上架史诗、
    专家 / 大师上架传奇卡（最高 20 绿宝石），价格按卡牌数值强度微调；老手级起可用 1 绿宝石换 1 星币。
    佩戴绿宝石骰子时不显示这条兑换。
  • 筹码商人（筹码商店方块为工作方块）：售卖筹码，品质与等级绑定 —— L1 稀有 / L2 稀有 + 史诗 / L3 史诗 /
    L4 史诗 + 传奇 / L5 传奇，出现权重 6 / 3 / 2；老手级同样解锁「1 绿宝石 → 1 星币」（绿宝石骰子时隐藏）。
  • 两个职业各用专用工作方块标签（原版共享标签仍然保留，村民照旧能发现并认领工作站），职业查看类模组不再把两家的方块显示成同一份。

抽奖盒（原「事件抽奖盒」）

  • 右键花 5 星币买一张抽奖牌，每 5:00 限购一次（余额不足或冷却中通过 ActionBar 红字拒绝）；
    换用新贴图与新配方（星盘·星币·星盘 / 星币·钻石骰子·星币 / 星盘·星币·星盘），手册附配方页。
  • 物品「事件抽奖牌」更名为「奇怪的问号」并换新图标（使用后从事件池随机抽一条事件，生存模式消耗 1 张）。
  • 卡牌商店 / 筹码商店 / 抽奖盒三个方块改为不可堆叠。

交易类筹码调整

  • 会员推荐信追加能力：装备期间自己商店内所有卡牌价格恒 −1 星币；与经商立牌的 10% 降价可以叠加，最低 0 星币（0 价直接拿走、不扣星币）。
  • ATM 机重写：每次向其他玩家转账时，转账双方各额外获得 1 星光与 2 星币（仅转账发起者装备时触发）。
    原「装备时获得 1 星光」与「星光兑换 +40%」两项能力已移除。
  • 星光兑换的「基础值下限」缺陷已修：银行卡-余额少 / 余额多提供的 +4 / +7 星光现在能正常兑换成星币
    （此前被当作装备期间的常驻下限，可兑换量恒被扣掉这部分）。

事件体系（重写）

  • 每个事件现在有统一的名称、图标、类型（正面 / 中性 / 负面，只影响文本颜色）、阶级、作用范围与可注册的触发方式，
    并支持每个事件独立计时器（重复触发会重置）。
  • 12 个事件（作用范围 = 触发者 64 格 ∪ 团队全体）：
    • 红温警告（攻击力 +5，3:00，正面）
    • 疾行（迅捷 II，2:00）
    • 雷暴将至（1 张随机卡；范围内敌对生物攻击力 +2、防御力 +2，2:00；夜间且附近有该状态的玩家时，敌对生物自然刷新数量 ×2）
    • 取长补短（受影响玩家里生命值最低者 +8、最高者 −8；先治疗、1 秒后再伤害）
    • 商店大酬宾（商店出售卡牌 +2，5:00）
    • 手牌抹杀（随机丢一张卡，卡牌直接消失、不掉落）
    • 天崩地裂（立即 4 点伤害）
    • 天降之物（1 张随机卡 + 3 星币，星币直接进钱包，正面）
    • 天使降临（4 点治疗）
    • 问题外卖（立即 2 点伤害 + 中毒 / 饥饿各 0:15 + 15 秒内治疗无效，负面）
    • 拥挤通道（所有玩家被传送到触发者位置，中性）
    • 战斗爽（2 张「攻击-特大」）
  • 状态指示器：红温警告 / 雷暴将至 / 问题外卖 会在效果栏显示同名图标；问题外卖生效期间原生中毒 / 饥饿图标由专用指示器取代。
    红温警告的攻击力加成与雷暴将至的攻 / 防加成走本模组战斗模型，且是瞬态（死亡或重登即消失）。
  • 事件卡动画：事件触发时屏幕正中弹出事件卡 —— 0.2s 淡入放大 → 1.0s 停留 → 0.2s 缩小淡出；
    上格事件图、下格事件名（按类型染色：正面绿 / 中性黄 / 负面红）+ 计时器。
    弹卡后约 1.9 秒（38 刻）才真正结算（28 刻可见动画 + 10 刻缓冲），计时器与效果、音效同刻登记；卡片文字与卡面同步淡出，不再残留。
  • 事件音效：event_fade_in（弹卡）、event_heal（治疗类）、event_damage（伤害类）、event_poisoning（问题外卖）、
    event_transport（拥挤通道）、event_bonus（天降之物）。
  • 大侦探立牌主动重做为「事件选择界面」：使用后弹出居中面板，从当前事件池随机抽 2 个事件（可出现相同事件、可任意正 / 负 / 中性组合）；
    鼠标指向卡片换成高亮底图，单击选中并保持，必须点确认才触发；顶部为 15 秒倒计时，
    超时 / 死亡 / 退出时强制触发第一个选项（已确认的选择不会被覆盖）。按下技能键那一刻立即播放主动音效，
    确认时不再播放，并当刻关闭界面直接进入事件流程。
  • 秘密侦探的「调查阶段」：只有击杀「隐匿调查」目标才会提升一阶（先按当前阶级触发、再升阶），

  • 事件动画播放期间的选择器统一拦截（2026-10-29）：动画播放的 38 tick 内，需要选择目标 / 弹出界面的主动技能与效果牌会被拒绝，并提示「事件动画播放中，请稍后再试」（不需要选目标的立牌技能照常可用）；动画一开始就会关掉已经打开的选择界面，动画结束后不会再突然弹出来抓住鼠标。

  • NeoForge 26.1.2 上「跃迁引擎 × Waystone（传送石碑）」的联动已正常启用（2026-11-02）：用传送石碑传送会照常被当作「Waystone 传送」结算 —— 同维度传送照常给跃迁引擎充能与迅捷，跨维度传送照常按 Waystone 传送处理；NeoForge 1.21.1 / Forge 1.20.1 / Fabric 1.20.1 三线行为与之一致，四条线没有差异。

平台差异（如实说明）

四条线的核心玩法与数值一致，但有四处行为因平台机制不同而不同。这不是遗漏，读之前先确认自己那条线的情况。

  • 筹码配方总开关只在三条线上生效：配置项 enable_chip_recipes 关闭时，NeoForge 1.21.1、Forge 1.20.1 与 NeoForge 26.1.2 会在配方加载期整批去掉筹码的合成配方。Fabric 1.20.1 没有「配方加载期条件」这一机制，所以即使开关关闭，Fabric 上筹码配方依然存在、依然能合成（要彻底禁用只能用数据包覆盖或删掉配方文件）。
  • 「材料带 NBT 要求」的配方实现不同：Fabric 线用自定义配方类型 astral_dice:nbt_shaped，另外三条线用 partial_nbt / 组件（components）。玩家看到的结果一样，差异只在数据文件层，不影响物品能否合成。
  • 图鉴（帕秋莉手册）在 Fabric 上多一道存在性门：Fabric 线生成图鉴的配方条目时会先检查 Patchouli 是否存在，没装 Patchouli 就不生成这批条目；另外三条线的表现是条目存在、但书本身打不开。
  • 1.20.1 两条线用铁砧代替重锤：star_coin_hammer_chip（星币锤）在 1.20.1 上用铁砧作为合成材料，1.21 及以后用重锤。1.20.1 没有重锤这件物品，这是版本必需。

What changed in 1.5.0 since 1.5.0-rc.7

The final stretch was four things: one guaranteed server crash fixed, the Abyss Reagent chip renamed consistently on all four lines, and two lines' local gaps closed. The sections below are the full picture since 1.3.7; this section only lists what landed after rc.7.

  • A guaranteed server crash is fixed: when a mob's attribute map has no attack_damage and that mob hit a player, the whole server went down (logged as Ticking entity). All four lines now check that the attribute exists first and treat a missing one as 0.
  • The “Abyss Reagent” chip is named consistently: display name, tooltip and every guide/handbook reference match now (ja_jp: 深淵試薬).
  • Fabric 1.20.1 gained the 6 missing signs' recipe-book unlocks (alana / ame / dorothy / jill / kangel / lingling). Those six recipes were reachable only through JEI and the handbook and never showed up in the recipe book; they do now.
  • Fabric 1.20.1: the Misaki Sign recipe ingredients are corrected - golden_star_plate became star_plate, matching the other three lines.
  • NeoForge 26.1.2 gained 2 Mamushi Sign exclusive combat cards in the creative tab (Bite attack_card_bite and Dragon's Roar attack_card_dragon_roar). Those two could only be granted by the Mamushi Sign's skills and had no creative-tab entry.

Combat rework

  • Separate defense formulas for players and mobs (both floor the result):
    • Player: 2 + armor × 0.30 + 0.85 × toughness (was 4 + armor × 0.30 + 0.85 × toughness) — base defense 4 → 2.
    • Mob: base defense + armor × 0.40 + 1.0 × toughness (was armor × 0.40).
    • Mob base defense: hostile 4 / neutral 3 / passive 0 (passive mobs no longer benefit from hostile-grade armor efficiency).
  • Defense bonuses are now converted 1:1: every point of “defense +X” from bank cards, signs and chips is worth exactly 1 defense.
    The old implementation multiplied by 2.0 armor and then applied the 0.30 / 0.40 coefficient, so only 0.6X landed for players and 0.8X for mobs —
    the effective strength is ×1.667 for players and ×1.25 for mobs compared to the previous build, which is why this version feels squishier. That is intended.
  • No lost fractions: defense enters combat as a double, so the 0.6 in 2 + armor×0.30 is no longer rounded away.
  • Zero dice still uses the formula: if either side has no dice equipped the roll counts as 0, but the attack/defense formulas still apply (no longer skipped).
  • Damage floor: when defense ≥ attack, final damage becomes max(1, attack × 15%) (previously a flat 1);
    reduction effects (Whetstone, Muscle Detective, …) apply after the final damage and may reduce it to 0.
  • Battle cards now roll decreasing dice (consecutive hits on the same target lower the die face by 1; a skill or a new target resets it):
    full-value chance 1–3 faces 55.6% → 25%, 1–6 faces 30.6% → 11.8%, 1–10 faces 19% → 6.9%, 1–20 faces 9.8% → 3.4% —
    expected damage drops 25–32%, flattening the “snowball in long fights” advantage.
  • Defense-card durability 10 → 150 (together with the 1:1 conversion, defense cards go from a one-shot shield to a real armor layer).
  • Dice blessing only triggers on a player's own melee attack: mob attacks on players and the defender's roll no longer trigger it.
  • Vanilla damage modifiers restored: Sharpness V +42.9%, critical +50%, Protection IV −64%, Resistance II −40% —
    the earlier rework had dropped them; vanilla is now applied first and the dice battle result stacks on top.
  • Damage numbers reworked: the value is the HP actually removed (pipeline result), not the theoretical damage;
    red = attack power and damage bonuses (including splash / chain / counter), green = spell and skill damage;
    multiple hits in the same tick on the same target in the same colour merge into one number;
    only the player who dealt the damage sees them (the victim sees them when there is no player owner); the position is fixed by the server at settlement and does not follow the target,
    with ±30° random spread so stacked numbers no longer overlap exactly.
  • Other flow changes: card stack size 64 → 16; effect-card cooldown starts when the card is played (each play in one cycle resets the 45s, charge caps at 30s);
    the healing timer now settles every 1:00 independently (no longer tied to the blessing cycle).

  • The double-damage curse used the wrong baseline (1.20.1): the old code took “the damage before difficulty scaling” as the baseline ⇒ on easy a commanded 10 landed as 6 and the intended 2.0× was computed as 1.2×; on hard it inflated the other way. It now takes the ratio from the correct damage event, and all three difficulties line up.

  • The Great Detective’s skill picker froze during global events (reported 2026-10-29): the event-choice screen is fully decoupled from the global-event timer — it opens normally while an event animation or another event is running and applies immediately on confirm; the countdown is no longer locked by events. ESC now really cancels: the screen closes, nothing triggers and no cooldown starts (previously ESC did nothing).

  • Selectors are blocked while an event animation plays (2026-10-29): during the 38-tick animation, active skills and effect cards that need a target or a screen are rejected with “An event animation is playing — please wait.” (sign skills that need no target still work). Starting an animation also closes any screen that is already open, so nothing pops up and grabs the mouse when the animation ends.

  • On NeoForge 26.1.2 the “Warp Engine × Waystone” linkage is now enabled (2026-11-02): a teleport-stone teleport is settled as a “Waystone teleport” there - a same-dimension teleport charges the Warp Engine and grants Speed as usual, and a cross-dimension one runs the Waystone path. NeoForge 1.21.1, Forge 1.20.1 and Fabric 1.20.1 are unchanged, so all four lines now behave the same.

Platform differences (stated plainly)

All four lines carry the same core gameplay and the same numbers, but four behaviours differ because the platforms differ underneath. This is not an oversight - know which line you are on before reading.

  • The chip-recipe master switch only takes effect on three lines: with enable_chip_recipes off, NeoForge 1.21.1, Forge 1.20.1 and NeoForge 26.1.2 drop the whole batch of chip crafting recipes at recipe-load time. Fabric 1.20.1 has no recipe-load-time condition mechanism, so with the switch off the chip recipes are still present and still craftable on Fabric (to remove them you have to override or delete the recipe files with a data pack).
  • “Ingredient with NBT requirements” recipes are expressed differently: Fabric uses a custom recipe type astral_dice:nbt_shaped, while the other three lines use partial_nbt / components. Players see the same result; the difference lives in the data files and changes nothing about what can be crafted.
  • The guide (Patchouli) has one extra existence gate on Fabric: Fabric generates its guide recipe entries only when Patchouli is present, so without Patchouli those entries are never generated; on the other three lines the entries exist and the book itself simply will not open.
  • The 1.20.1 lines substitute an anvil for the mace: star_coin_hammer_chip (Star Coin Hammer) is crafted from an anvil on 1.20.1 and from the mace on 1.21 and later. 1.20.1 has no mace item, so this is required by the version.

Known issues and design notes

  • This release covers all four platform lines (NeoForge 1.21.1 / Forge 1.20.1 / NeoForge 26.1.2 / Fabric 1.20.1); the only mechanical differences between them are the four listed under “Platform differences” above.

  • The generic card-choice screen has its logic wired but no skill uses it yet, so it is not visible.

  • Crafting for the 6 new chips follows enable_chip_recipes (off by default); enable it in the config if you want recipe access. (Updated 2026-10-28: five of those six — Flashlight-Burst, Fortune Slip, Abyss Reagent, Wireless Power Pole and Sensor Device — had no recipe at all and now have one; whether you can craft still depends on that switch.)

  • “Reinforced Repulsion” is an exclusive card: not in the random pool, no recipe, not in bounty pools. Its item form is deliberately hidden from the creative tab and JEI. (Updated 2026-10-27: Reinforced Repulsion is also bound to the Lingling Sign — see “New effect cards” above.)

  • This is a stable release: numbers are as of post-1.5.0-rc.7, and later balance changes ship in new versions. Feedback is still welcome.

  • Villagers that already exist keep the offers cached in the save file; they only adopt the new price table after levelling up or re-claiming a workstation.

  • “Minimum price” means the base offer: vanilla reputation and Hero of the Village discounts can still lower what you actually pay, so 20 (chips) / 5 (cards) is not a hard transaction floor.

Text and manual

    and entries that still described the old defense formula were corrected.
  • Battle-card and dice-battle text rewritten: “roll twice, take the max” is gone, the dice roll counts as 0 when no dice are equipped,
