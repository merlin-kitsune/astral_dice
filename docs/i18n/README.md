## 二、口径（关键决定）

1. **专有名词一律取官方日语名。** 《星引擎派对》英文名 **Astral Party**，**日服 2025-05-20 开服**，官方日文名「アストラルパーティー」。官方名只存在于日服客户端，故靠权威二手源反查：
   - **B站《吉星派对》wiki** 的角色页有**结构化字段** `|英文名=|日文名=`（覆盖模组全部 23 个立牌角色）——**本次主要来源**；
   - **日服玩家实测文章**（note.com，日语）—— 唯一能拿到筹码官方日语名的来源（`エアバッグ` / `レールガン` / `永久機関` / `ライトニングコア` / `電撃グローブ` / `エナジーソード` / `ワープエンジン` / `エネルギー回収`）；
   - **JP 官方公告原文** —— 世界术语（`スターコイン` 星币 / `星盤` 星盘 / `チップ` 筹码 / `カード` 卡牌 / `マップ` 地图 / `キャラクター` 角色 / `スキン` 皮肤）；
   - ⚠️ **wiki.gg(zh) 不可采信其日文名**：`Fen`/`Padman`/`Mimi` 三家被写成同一个 `パルナン`/`ファニィ`（复制错误）。
2. **「立牌」= `スタンド`**（用户裁决：沿用原有名词，**不用**「看板／支架」）；「看板娘」这一角色直接用官方日语名 **ミミ**。立牌名统一 `<角色官方日语名>のスタンド`。
3. **物品名按英文显示名翻译**（用户裁决），依已实证的规律：英语外来词→片假名；日语既有汉字词→汉字复合（`永久機関` / `エネルギー回収` / `星盤`）。
   - 验证：用「官方英文名→自然日语」推出的 8 个筹码名与日服官方名 **8/8 吻合**。
   - 筹码/卡牌按**中文名反查** wiki 定位对应条目（筹码 62 命中 56、卡牌 34 命中 28，含 4 处人工对齐）。
   - 模组原创内容（`高级外设`、`原初核心` 等 12 项）wiki 无条目 ⇒ **直译**。
4. **原版效果名取 MC 官方 ja_jp**（`effect.minecraft.*`），**不要按中文自译**：
   `resistance`=`耐性`（不是「耐性上昇」）、`saturation`=`満腹度回復`（不是「飽和」）、`blindness`=`盲目`、
   `wind_charged`=`蓄風`、`weaving`=`巣張り`、`oozing`=`滲出`、`infested`=`虫食い`、
   `raid_omen`=`襲撃の予感`、`trial_omen`=`試練の予感`。
   离线取证留档：`temp/ref/mclang/ja_jp_1211.json`、`ja_jp_1201.json`。
5. **结构标记逐字保留**：染色码（`§e/§9/§7/§r/§c/§f`）、`%%` 转义、格式符（`%s/%d/%1$s`）、换行结构。
   脚本对**各线自己的中文原文**断言「换行数 / `§` 数 / `%` 数」全等。

## 四、校验结果（2026-09-22）

- `gen_ja_lang.py --check`：三线各 **805/805 键覆盖**；换行/`§`/`%` 不一致 **0 条**。
- `tools/check_lang_sync.ps1`：三线 `OK`、**0 WARN**、退出码 0（即 zh/en/ja 三方 key 一致 + 无裸 `%`）。
- **反例验证**：临时植入裸 `%` ⇒ `[FAIL] …(ja): 含未转义字面百分号` + rc=1；删一个键 ⇒ `[FAIL] … 缺失于 ja_jp.json` + rc=1。
- **构建**：三线 `MT_BUILD: OK`；开 jar 核对 —— 各 jar 内 `ja_jp.json` **805 键**、抽查文案正确。
- **实机取证**（1.21.1 切 `lang:ja_jp`）：
