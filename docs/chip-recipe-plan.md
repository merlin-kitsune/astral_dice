> **两档互不越界**：统一规范（品质底行 + 第二行中位空白筹码 + 流派材料）**只作用于非进阶筹码**（基础/流派/新补）；进阶筹码一律走「通用升级」模板，任何配方统一/生成工作都不得改写它们。详见 `AGENTS.md`「筹码一览 → 筹码配方规范」。
>
> 配方数据由 `scripts/verify/ChipCommon.psm1` 的 GRID / UPGRADE / UPGRADE_TEMPLATE 驱动；渲染脚本已于 2026-09-15 随 `temp/` 清理移除，本表此后手工维护。

>
> 校验：`python scripts/verify/verify_chip_recipes.ps1` → 双版本 × 三档（源码 / 生成资源 / jar）全绿（59/59）。
