二、新掷骰口径

权重 w(j) = (2n − 1) − j，其中 n = max − min + 1、j = 结果 − min（0 基）。 最低点权重 2n−1、最高点权重 n ⇒ 严格递减，比值 ≈ 2 : 1； 总权重 n(3n−1)/2（恒为整数）。抽样 = 一次 nextInt(总权重) + 线性累计权重扫描（逆变换法）。

满值率闭式 = 2/(3n−1)；旧口径为 (2n−1)/n² 且中位数被抬到区间 67%~100% 处（10 → 8、20 → 15）—— 这正是「战斗牌提供的伤害非常可观」的主因。
