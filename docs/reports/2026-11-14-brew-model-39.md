# 【仙酿】新模型落地与实机渲染核对（26.4-SNAPSHOT.39）

- 日期：2026-11-14
- 任务来源：用户要求把金鲤立牌的【仙酿】替换为新的 `models/winegourdbetter.bbmodel` 模型，并核对游戏内效果与 Blockbench 是否一致。
- 目标：`astral_dice:souri_drink` 的 `Variant=1`（BREW = 仙酿）。

## 1. 资产与生成

| 项 | 值 |
|---|---|
| 源模型 | `models/winegourdbetter.bbmodel`（bedrock 4.10，130 bones / 724 elements，128×128 UV） |
| 生成器 | `build/tmp-dsh/gen_winegdbetter.py`（--apply 落盘；默认 dry-run） |
| 几何 | GeckoLib `1.12.0`；`geo/winegourdbetter.geo.json` sha256 前 16 位 `1c760d12da6b2047` |
| 贴图 | `textures/entity/winegourdbetter.png`，9965 B，sha256 前 16 位 `8227d5b2fecafd98` |

生成规则（由「旧 bbmodel ↔ 仓库内旧 geo」反推，并用重新生成旧 geo 逐骨骼比对自检通过，容差 1e-4）：

- 骨骼 pivot = `(-x, y, z)`，rotation = `(-rx, -ry, +rz)`，parent 取 DFS 父组名；立方体只收集组内直接 children（子组各自成骨）。
- cube origin = `(-max(from.x), min(from.y), min(from.z))`，size = 各轴跨度绝对值；带旋转的立方体 pivot 用 `(-origin.x, y, z)`，rotation 同骨骼符号规则。
- UV：north/south/east/west/up 取 `(minx, miny)`、size = `(|dx|, |dy|)`；down 面取 `(minx, maxy)`、size = `(|dx|, -|dy|)`。
- visible_bounds_width/height = range / 16，offset = 包围盒中心 / 32（x 取负）；testure_width/height = bbmodel resolution。

落地文件（五线一致）：

- neoforge-1.21.1 / forge-1.20.1 / fabric-1.20.1 / fabric-1.21.1：`src/main/resources/assets/astral_dice/geo/winegourdbetter.geo.json` 与 `textures/entity/winegourdbetter.png`。
- neoforge-26.1.2：`src/main/resources/assets/astral_dice/geckolib/models/winegourdbetter.geo.json` 与同名贴图（GeckoLib 5 的目录约定，与仓库内既有 `winegourd.geo.json` 位置一致）。
