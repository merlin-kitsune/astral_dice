## 6. 新发现的缺陷（未修，待裁决）

**`ChipShopService.grantRefresh` 用引用比较判断「无变化」**：
```java
ChipShopState next = state.withRefreshGranted();
if (next == state) return false;   // 应为 equals / 字段比较
```
`withRefreshGranted()` 每次 new 一个 record，所以 `next == state` 恒 false，**刷新次数到上限 5 时仍返回 true**（状态值不变）。实测：`withRefreshGranted().equals(cur)=true`、`(next==cur)=false`、`grantRefresh` 在 r=5 返回 true。
位置：`neoforge-26.1.2/.../ChipShopService.java:105`、`neoforge-1.21.1/...:103`、`forge-1.20.1/...:71`（三线同款）。影响：调用方若用返回值判断「是否真的发券」会误判；未发现存档损坏。建议改成 `next.equals(state)` 或 `next.refreshesLeft()==state.refreshesLeft()`（需先 bump .14 再动产品代码，本轮未改）。
