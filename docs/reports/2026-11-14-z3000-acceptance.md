## 2. 实现落点

- 注册：`neoforge-1.21.1/src/main/java/com/merlinkitsune/astral_dice/item/ModItems.java:1194`、`forge-1.20.1/.../ModItems.java:1174`、`neoforge-26.1.2/.../ModItems.java:1053` 注册 `z3000_sign`（稀有）。
- 主动/被动：`.../item/sign/Z3000SignItem.java`，关键常量在 1.21.1 版本 :42-47：
  - `RANGE=16.0D`、`ACTIVE_DAMAGE=5.0F`、`ATTACK_CAP=12`
  - `HEALTHY_KILLS_PER_STACK=2`、`HEALTHY_KILL_THRESHOLD=20.0D`
  - `COOLDOWN_REDUCTION_INTERVAL_TICKS=1200L`（每分钟一次）
- 拖拽：`GrapplingHookEntity` 接收 `impactDamage` / `grantCounterOnKill`；到点后 `placeTarget` → `hitTarget` → 结束，伤害走 `ModDamageTypes.skillDamage`。
- 持久状态：`component/ModAttachments.java:2642-2679` 新增攻击叠层、≥20 血击杀计数、上次冷却缩减时间三个附件。
- 反击层保留：`item/RenShieldManager.java` 的护盾清理与 `tick()` 保留条件均加入 `Z3000SignItem.isEquipped(player)`，避免 Z3000 层数被其他立牌的清理逻辑抹掉。
- 资源/文案：三线各 3 个语言文件含 `item/tooltip/msg/guide` 键；tooltip 在 `event/ModTooltipHandler.java`（1.21.1 :1765 起、1.20.1 :1730 起、26.1.2 :1826 起）显示主动、被动、`攻击 +n/+12`、`x/2` 与剩余冷却。
- 配方：`HRH / ISI / TDT`，H=漏斗、R=红石、I=铁锭、S=空白立牌、T=铁粒、D=普通骰子；三线 recipe/advancement 已生成，配方唯一性脚本三线 `collisions=0`。

## 5. 尚未覆盖 / 风险

1. Fabric-1.20.1 / 1.21.1 只有版本号 bump，没有 Z3000 代码、资源或实机；不得对外声称 Fabric 可用。
2. 1.21.1 的攻击叠层封顶与低血排除只有链路日志，没有 1.20.1/26.1.2 那样的读数；在补齐读数前只能算“链路通过、数值未完整取证”。
3. Z3000 没有单独做视觉截图验收；拖拽沿用抓钩渲染，吸尘头仍是薄片模型（源 bbmodel 高度 1.8px），是否加厚由用户另行裁决。
4. 1.21.1 / 1.20.1 的整套实机在 `.31`；最终 `.32` 只对 26.1.2 做了修复并重跑，这两线的 `.32` 产物未重跑。若要把 `.32` 作为三线统一发布候选，需补跑这两线。
