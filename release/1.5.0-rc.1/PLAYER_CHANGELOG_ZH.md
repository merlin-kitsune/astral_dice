# 星之骰戏 (Astral Dice) 1.5.0-rc.1 玩家更新日志

已发布：1.5.0-rc.1（**预发布 / Beta**）—— 覆盖自 1.3.7 以来的**全部**改动。这是一次大版本跳跃，主要变化：

- **商店体系**：方块「卡牌商店」与「筹码商店」、村民职业「卡牌交易员」与「筹码商人」、方块「抽奖盒」；
- **事件体系**：12 个事件 + 事件卡动画 + 大侦探的「事件选择界面」；
- **内容**：两张奇特立牌（超天酱 / 地雷女）、两张新效果牌（路障 / 强化拒止，后者另有物品形态）、5 枚新筹码；
- **战斗系统重做**：防御公式按玩家 / 生物分离、防御力 1:1 折算、生物攻击纳入骰战、伤害下限改为攻击力的 15%、战斗牌改为单次递减掷骰、防御牌耐久 150、原版伤害修饰器回归、伤害跳字按类型分色；
- **界面**：战斗数值条（防御力条 / 攻击力条）、Jade 联动、商店冷却倒计时；
- **许可**：源代码改为 GPL-3.0-only。

> **本预发布只提供两个构建**：`astral_dice-1.5.0-rc.1+neoforge_1.21.1.jar`（Minecraft 1.21.1 / NeoForge）
> 与 `astral_dice-1.5.0-rc.1+forge_1.20.1.jar`（Minecraft 1.20.1 / Forge）。其它平台线不在本次预发布范围内。

## 安装与前置（必读）

- **本版起 StarEngine 不再内嵌**（NeoForge 1.21.1 / Forge 1.20.1）：发货 jar 里已删除内嵌库
  （jar 内不再含 `META-INF/jarjar/`），StarEngine（modId `starengine`，**1.1.0**）改为**独立前置**，
  必须自己下载对应加载器的 `starengine-<加载器>-1.1.0.jar` 放进 `mods`。版本需与本体构建时一致；
  缺库会以「Missing or unsupported mandatory dependencies」拒绝启动 —— 看到这句话先检查库 jar 是否漏装。
- 1.20.1 的 Mixin 运行时：**Mixin Booster ≥0.1.3** 或 **Sinytra Connector**，**二选一**即可。
- **卡牌不再能合成**：22 条卡牌合成配方已移除，卡牌改为通过卡牌商店 / 卡牌交易员 / 骰子与立牌等方式获得。
- 1.3.7 及以前的存档可以直接升级；商店、事件、村民等新内容都是新增内容，不会改写旧存档里的物品。

## 新增内容

### 卡牌商店（新方块）

- **合成**：上排 3 个平滑石台阶、中排 3 枚星币、下排 3 个原木（3×3 工作台）。放下后**右键打开**，无消耗、无冷却。
- **货架**：基础上架 **3 张卡牌**（同一批不会出现两张同名卡），**基础价 3 枚星币**；
  每格买走后显示「已售出」；**同一批卡持续有效**，只有 60 秒轮询归零那一刻才换一批（关掉再开不刷新）。
- **经商立牌联动**：同队有人佩戴「经商立牌」时额外上架 **1 张战斗牌**，且每张牌各有 **10%** 概率降价为 **1 枚星币**。
- **蓄力牌**只有在**骰子星级 ≥ 2** 时才会出现在货架。
- **界面**：带玻璃展示窗的木质柜台（Blockbench 模型，碰撞与选中框随模型收紧）；品红标题「卡牌商店」居中；
  6 个卡框，卡面填满、卡名完整显示（过长自动缩字号）；折扣牌在**卡面右下角**标出；
  左侧按钮 = 星光兑换星币，中间按钮 = 转账（星币少于 5 枚或冷却中灰化），沙漏按**冷却进度**显示；
  左下为星币余额条，右下为玩家物品栏。
- **购买改为「拖拽成交」**：按住货架上的卡牌拖到右下物品栏才算购买 —— 拖动时卡牌跟随光标、原卡位显示「已售出」底图；
  没拖到物品栏就自动移回（不扣钱）；**星币不足时拖不动**（红字提示所需星币）；落点格被占用会提示换一格。
  空槽位统一显示「已售出」样式。
- **购得即视为「获得」**：会正常触发维生素药丸的治愈与提尔立牌的狐光层数；购买成功播放钱包音效。
- **界面细节**：按钮改为纯图标（说明移到悬停提示）；转账页面完全独立（打开转账时商店内容一律不渲染）；
  转账金额为 **4 档按钮**（5 / 10 / 15 / 20），带玩家名搜索框、滚动列表、每行显示头像 + 名字 + 当前余额，
  选中行有粉色箭头指示；转账成功后自动退回商店主界面，**同一轮内不能再次转账**。

### 卡牌商店内的「星光兑换」与「转账」

- **星光兑换**：**2 点星光 = 1 枚星币**，**无冷却**，每轮一次（星光不足时给提示）。这是「经商立牌」原主动「套现」迁入商店后的入口。
- **转账**：把星币转给**同服务器其他在线玩家**，单次 **5~20 枚**，每次转账后 **60 秒**冷却（与商店换牌共用同一个计时器，掉线也照算）；
  目标在确认前离线会自动刷新名单并提示重选；每轮一次。
  **佩戴「经商立牌」的玩家转账成功后**，自己货架上**顺序第一张**未售出的卡牌会被强制降到 1 星币。

### 筹码商店（新方块）

- **合成**：`金锭 · 星盘 · 金锭 / 磨制黑石砖块 · 空白筹码 · 磨制黑石砖块 / 磨制黑石砖块 ×3`（3×3 有序）。
- **一次给出 3 个筹码格**，从**你尚未拥有**的筹码中按权重抽取（同一批不重复），每格显示该筹码自己的图标，三格**同价**。
- **价格**：从 **10 枚星币**起步，**同一个玩家每买过一枚就 +5**、上限 **100**（刷新或重开都不重置）。
- **品质按骰子星级加权**：0–1★ = 稀有 60% / 史诗 37% / 传奇 3%；2★ = 40% / 45% / 15%；3★ = 25% / 50% / 25%。
- **流派权重**：你**已装备的同流派筹码**会让该流派更容易被抽到（每枚 **+60%**）；**上一次买下的类别**在本批**第一格**权重 **×2**（第二、三格 **×1.25**）。
- **刷新**：初始 **3 次**、上限 **5 次**，**用掉第一次刷新后**才开始计时，每 **30 分钟**恢复 1 次（不在店里也照常累积）；
  次数用尽时刷新按钮只闪红、不再发包。**已集齐全部筹码**或**物品栏没有空位**时无法开店（会给提示）。
- **购买**：买下后筹码直接进物品栏并关闭界面；**购买后商店进入 5:00 冷却**；冷却中**右键空白筹码**可把它投入商店 ——
  立即解除冷却并 **+1 次重抽**，每 2:00 限一枚。物品栏满时**照常成交**：扣款、次数 +1、候选重抽都照常，
  装不下的那枚**掉在脚边**并提示；创造模式下按原版规则直接被吞掉（不掉落、无提示）。
- **界面**：花费栏 = 星币小图标 + 金额；刷新只显示**剩余次数**；候选图标 **24×24**；候选格脚下按品质画**三色描边环**（稀有蓝 / 史诗紫 / 传奇金）；
  过长筹码名**左右滚动**；被选中的格子名称改**黑字**；鼠标悬停候选筹码（**筹码格或其下方标签**都算命中）即弹 tooltip。
  商店**不绘制标题**；**没有任何折扣路径**（「会员推荐信」的减价只作用于卡牌商店）。

### 村民职业

- **卡牌交易员**（卡牌商店方块为工作方块）：新手 / 学徒上架**稀有**卡（2–6 绿宝石）、老手 / 专家上架**史诗**、
  专家 / 大师上架**传奇**卡（最高 20 绿宝石），价格按卡牌数值强度微调；**老手级**起可用 **1 绿宝石换 1 星币**。
  **佩戴绿宝石骰子时不显示这条兑换**。
- **筹码商人**（筹码商店方块为工作方块）：售卖筹码，品质与等级绑定 —— L1 稀有 / L2 稀有 + 史诗 / L3 史诗 /
  L4 史诗 + 传奇 / L5 传奇，出现权重 6 / 3 / 2；老手级同样解锁「1 绿宝石 → 1 星币」（绿宝石骰子时隐藏）。
- 两个职业各用**专用工作方块标签**（原版共享标签仍然保留，村民照旧能发现并认领工作站），职业查看类模组不再把两家的方块显示成同一份。

### 抽奖盒（原「事件抽奖盒」）

- 右键花 **5 星币**买一张抽奖牌，每 **5:00** 限购一次（余额不足或冷却中通过 ActionBar 红字拒绝）；
  换用新贴图与新配方（`星盘·星币·星盘 / 星币·钻石骰子·星币 / 星盘·星币·星盘`），手册附配方页。
- 物品「事件抽奖牌」更名为「**奇怪的问号**」并换新图标（使用后从事件池随机抽一条事件，生存模式消耗 1 张）。
- 卡牌商店 / 筹码商店 / 抽奖盒三个方块改为**不可堆叠**。

### 交易类筹码调整

- **会员推荐信**追加能力：装备期间**自己商店内所有卡牌价格恒 −1 星币**；与经商立牌的 10% 降价**可以叠加**，**最低 0 星币**（0 价直接拿走、不扣星币）。
- **ATM 机重写**：每次向其他玩家转账时，**转账双方各额外获得 1 星光与 2 星币**（仅转账发起者装备时触发）。
  原「装备时获得 1 星光」与「星光兑换 +40%」两项能力**已移除**。
- **星光兑换的「基础值下限」缺陷已修**：银行卡-余额少 / 余额多提供的 +4 / +7 星光现在**能正常兑换成星币**
  （此前被当作装备期间的常驻下限，可兑换量恒被扣掉这部分）。

### 事件体系（重写）

- 每个事件现在有统一的名称、图标、类型（正面 / 中性 / 负面，**只影响文本颜色**）、阶级、作用范围与可注册的触发方式，
  并支持**每个事件独立计时器**（重复触发会重置）。
- **12 个事件**（作用范围 = 触发者 64 格 ∪ 团队全体）：
  - **红温警告**（攻击力 +5，3:00，正面）
  - **疾行**（迅捷 II，2:00）
  - **雷暴将至**（1 张随机卡；范围内敌对生物攻击力 +2、防御力 +2，2:00；**夜间且附近有该状态的玩家时，敌对生物自然刷新数量 ×2**）
  - **取长补短**（受影响玩家里生命值最低者 +8、最高者 −8；**先治疗、1 秒后再伤害**）
  - **商店大酬宾**（商店出售卡牌 +2，5:00）
  - **手牌抹杀**（随机丢一张卡，**卡牌直接消失、不掉落**）
  - **天崩地裂**（立即 4 点伤害）
  - **天降之物**（1 张随机卡 + 3 星币，**星币直接进钱包**，正面）
  - **天使降临**（4 点治疗）
  - **问题外卖**（立即 2 点伤害 + 中毒 / 饥饿各 0:15 + **15 秒内治疗无效**，负面）
  - **拥挤通道**（所有玩家被传送到触发者位置，中性）
  - **战斗爽**（2 张「攻击-特大」）
- **状态指示器**：红温警告 / 雷暴将至 / 问题外卖 会在效果栏显示同名图标；问题外卖生效期间原生中毒 / 饥饿图标由专用指示器取代。
  红温警告的攻击力加成与雷暴将至的攻 / 防加成**走本模组战斗模型**，且是**瞬态**（死亡或重登即消失）。
- **事件卡动画**：事件触发时屏幕正中弹出事件卡 —— 0.2s 淡入放大 → 1.0s 停留 → 0.2s 缩小淡出；
  上格事件图、下格事件名（按类型染色：正面绿 / 中性黄 / 负面红）+ 计时器。
  **弹卡后约 1.9 秒（38 刻）才真正结算**（28 刻可见动画 + 10 刻缓冲），计时器与效果、音效同刻登记；卡片文字与卡面同步淡出，不再残留。
- **事件音效**：`event_fade_in`（弹卡）、`event_heal`（治疗类）、`event_damage`（伤害类）、`event_poisoning`（问题外卖）、
  `event_transport`（拥挤通道）、`event_bonus`（天降之物）。
- **大侦探立牌主动重做为「事件选择界面」**：使用后弹出居中面板，从当前事件池随机抽 **2 个**事件（可出现相同事件、可任意正 / 负 / 中性组合）；
  鼠标指向卡片换成高亮底图，单击选中并保持，**必须点确认**才触发；顶部为 **15 秒倒计时**，
  超时 / 死亡 / 退出时强制触发第一个选项（已确认的选择不会被覆盖）。按下技能键那一刻立即播放主动音效，
  确认时不再播放，并**当刻关闭界面**直接进入事件流程。
- **秘密侦探的「调查阶段」**：只有击杀「隐匿调查」目标才会提升一阶（**先按当前阶级触发、再升阶**），
  4 张分阶图标接线（调查阶段 I / II / III / 真相揭露），所有阶级持续时间均为 **1:00**；
  队内多名秘密侦探各自独立；**已被施加「隐匿调查」的目标不能再次被任何人施加**；
  击杀时除「真相揭露」阶级外，事件只作用于**施加调查的那名秘密侦探与该击杀者**。
  该事件**只有在队内存在秘密侦探时才可能被抽到**。
- **两个抽事件入口**：物品「奇怪的问号」与方块「抽奖盒」。
- **模组内所有星币发放统一「优先进钱包」**：海清、邦妮、汉娜、米米、天降之物与大侦探被动等不再直接塞物品栏
  （放不下就掉地上），而是**先入钱包余额**，钱包关闭时才给物品。

### 新立牌

- **超天酱立牌**（奇特；配方：紫晶骰子 + 黄金星盘×2 档）
  - 主动「网络天使」：立即获得（1 + 粉丝数）枚星币（最多 10 枚）；粉丝数 ≥3 时恢复全满、≥9 时友方玩家各得 3 星币
    （有队伍覆盖全队，无队伍覆盖 64 格内其他玩家）。
  - 被动「小天使请安」：使你攻击或攻击你的目标成为「粉丝」（永久状态），**粉丝攻击你时伤害 −1**。
  - 备注「一心同体」：队内有地雷女时该被动同样对其生效（她的粉丝计数归你）。粉丝数上限 10、跨死亡保留、卸下立牌清零。
- **地雷女立牌**（奇特；配方同上）
  - 主动「感情过量摄入」：立即恢复「爱」层数 ×2 的生命值，并获得 1:00 移动速度 +20%；时间结束后扣除 4 层「爱」且「爱」上限 +1（最多 32）。
  - 被动「无法承受的爱」：基础防御 6 点；受到敌对攻击每 30 秒 +1 层「爱」（装备时初始 2 层、上限初始 4 层）；
    每层「爱」攻击力 +1、防御力 −1（最低 0）；「爱」超过 4 层时每超出 1 层 +1 最大生命值。
  - 备注「一心同体」：队内有超天酱时她获得 6 点基础防御，且她受伤时队内所有地雷女各 +1 层「爱」。
    「爱」跨死亡保留、卸下立牌清零。
- **史莱姆立牌被动「细胞分裂」改为每 15 秒最多触发一次**（仍 +1 层治愈、主动技能冷却 −10 秒）。
- **枪匠立牌主动 / 被动重写**：主动「弱点反击」改为指定一个目标并施加「破绽 (2:00)」（目标战斗骰点锁定为 0，
  只能对没有「破绽」的目标施加）；被动「弱点识破」与怪力侦探「推理时间」的衰减改为**各自独立的 1 分钟计时器**
  （不再挂在骰神赐福上；界面上改为显示剩余时间）。

### 新效果牌

- **路障**（稀有）：右键视线命中的方块面放置（最远 4.5 格，遵循原版放置规则；放不下时失败且**不消耗卡牌**）。
  由**可见实体 + 隐形碰撞方块**组成：**30 点耐久**，被生物攻击一次固定 **−1**（玩家也可以把它拆掉）；
  碰撞箱 **1.5 格高**，像栅栏一样阻挡玩家与生物；箭与弩弹在方块层被接住并同样 −1；爆炸也推不动它。
  服务端每 4 tick 把半径 6 格内**非精英、非 Boss** 的敌对生物仇恨转到路障上。
  耐久耗尽 / 被玩家打光 / 被 `/kill` / 被 `/astralparty killbarricade` 清除时解除仇恨、删除碰撞方块、播放木头破碎音；
  **不掉落物品、不给经验**。已加入随机效果牌池、创造栏与赏金奖励池。
- **强化拒止**（奇特、专属：仅获得者可用）：右键视线命中的方块面放置（最远 4.5 格，放不下不消耗）。
  无碰撞方块的力场实体，**50 点耐久 / 20:00 寿命**；每 1 秒把 **12 格**内**当前有仇恨目标的**敌对 / 被激怒中立生物拉入吸附集合，
  并持续施加**缓慢 (0:10)** 与**虚弱 (0:10)**；每 tick 把跑出 12 格的目标拉回 **11.5 格**；**不吸引仇恨**（全程不改写目标）；
  被吸附的苦力怕**无法自爆**；怪物与环境伤害对它无效。**每 10 秒按当前吸附目标数扣耐久（单次最多 5 点）**。
  放置者**近战命中 5 次**可把它**回收成物品形式**（其他人打它只会收到提示）。
  专属牌**不进随机池、无配方、不进赏金池**，也不出现在商店与村民交易里。
- **强化拒止（物品形态）**：回收后的物品携带**耐久（上限 50）/ 已存活 tick（剩余寿命，上限 20:00）/ 已发放充能（0–5）**三份状态，
  再次放置按完全同一套判据恢复；非获得者既无法放置也无法回收。物品形态**不列入创造栏与 JEI**（仍可正常获得与使用）。
- **`/astralparty` 新增清场子命令**：`killbarricade [<radius>|all]` 与 `killrepulsion [<radius>|all]`
  （权限等级 2；省略半径默认 64 格，`all` 清当前维度），用于清掉拿不到实体 id、`/kill` 也打不掉的遗留实体。

### 新筹码（5 枚，筹码池 61 → 66；稀有 19 / 史诗 28 / 传奇 19）

- **手电筒-爆闪**（传奇 / 星光）：攻击「**该玩家**未攻击过的**敌对**目标」时星光 +1（去重粒度 = 玩家 × 目标，上限 256）；每 2 层星光 +1 点攻击伤害。

## 战斗系统重做

- **防御力公式按玩家 / 生物分离**（均向下取整）：
  - 玩家：`2 + 护甲 × 0.30 + 0.85 × 韧性`（原为 `4 + 护甲 × 0.30 + 0.85 × 韧性`）——**初始防御 4 → 2**。
  - 生物：`生物初始防御 + 护甲 × 0.40 + 1.0 × 韧性`（原为 `护甲 × 0.40`）。
  - 生物初始防御：敌对 **4** / 中立 **3** / 被动 **0**（被动生物不再享受和敌对生物一样的护甲效率）。
- **防御类加成改为 1:1 折算**：银行卡、立牌、筹码等「防御力 +X」现在**每 1 点直接等于 1 点防御**；
  旧实现按 2.0 倍护甲再乘 0.30 / 0.40 的系数折算，导致玩家侧只兑现 0.6X、怪物侧 0.8X ——
  **实际强度相比旧版是玩家 ×1.667、生物 ×1.25**，所以这件预发布里玩家会觉得「变脆了」，这是刻意的平衡调整。
- **不吞小数**：防御力按 double 终值参与结算，`2 + 护甲×0.30` 里的 0.6 不再被取整丢掉。
- **骰点为零时公式仍生效**：双方任一方未装备骰子时骰点按 0 计，但防御力 / 攻击力公式照常参与对拼（不再整段跳过）。
- **伤害下限**：当防御点 ≥ 攻击点时，最终伤害改为 `max(1, 攻击力 × 15%)`（此前固定 1 点）；
  **减免类效果（磨刀石、怪力侦探等）在最终伤害之后结算，允许把伤害扣到 0**。
- **战斗牌改为单次递减掷骰**（同一目标连续命中时骰面上限逐次 −1，技能或换目标后重置）：
  满值命中率 1~3 面 55.6% → 25%、1~6 面 30.6% → 11.8%、1~10 面 19% → 6.9%、1~20 面 9.8% → 3.4%，
  **期望输出整体下降 25~32%**，长战斗里的「越打越强」收益被压平。
- **防御牌耐久 10 → 150**（配合上面的 1:1 折算，防御牌的作用从「一次性小盾」变成真正的一层护甲）。
- **骰神赐福只能由玩家主动近战触发**：生物攻击玩家、以及防御方掷骰都**不再**触发。
- **原版伤害修饰器回归**：锋利 V **+42.9%**、暴击 **+50%**、保护 IV **−64%**、抗性 II **−40%** ——
  此前本模组的重做把原版加成丢了，这次接回原版管线后再叠加骰战结果。
- **伤害跳字重做**：数值 = **本次实际扣血**（管线终值），不再显示「理论伤害」；
  **红** = 攻击力与伤害加成（含溅射 / 波及 / 反击），**绿** = 法术与技能伤害；
  同一 tick、同一目标、同色的多段伤害**合并成一条**（例：一发激光连穿三个目标各显示各自一条，同级联的三段攻击只显示合计一条）；
  **只发给造成伤害的玩家本人**（没有玩家归属时发给受击者）；位置在结算那一刻由服务端固定、**不跟随目标移动**（避免追随箭头），
  并带 **±30°** 随机扩散，多段伤害的数字不再完全重叠。
- **其它流程**：卡牌堆叠 **64 → 16**；效果牌冷却**出牌即开始计时**（同一轮内每次出牌都会重置 45 秒、充能封顶 30 秒）；
  治愈计时器改为**每 1:00 独立结算一次**（不再与赐福周期耦合）。

- **生物喝牛奶卡顿**：非玩家实体清除效果时不再走原版的逐帧重算，修掉大批生物同时喝奶造成的卡顿。
