# 星之骰戏 (Astral Dice) 1.5.0-rc.1 更新日志

已发布：1.5.0-rc.1（**预发布 / Beta**）—— 覆盖自 1.3.7 以来的全部改动。这是一次大版本跳跃：
**商店体系**（卡牌商店 / 筹码商店两个方块 + 卡牌交易员 / 筹码商人两个村民职业）、**事件体系**（12 个事件 + 事件卡动画 + 事件选择界面）、
**两张奇特立牌**（超天酱 / 地雷女）、**两张新效果牌**（路障 / 强化拒止，后者另有物品形态）、**5 枚新筹码**、
**战斗系统重做**（防御公式分离与 1:1 折算、生物纳入骰战、战斗牌单次递减掷骰、防御牌耐久 150、原版伤害修饰器回归）、
**战斗数值条 HUD**，以及许可改为 GPL-3.0-only。

## 安装与前置（必读）

- **本版起 StarEngine 不再内嵌（NeoForge 1.21.1 / Forge 1.20.1）**：发货 jar 里已删除内嵌库，
  StarEngine（`starengine`，**1.1.0**）改为**独立前置**，必须自己下载对应加载器的
  `starengine-<加载器>-1.1.0.jar` 放进 `mods`。**版本必须与本体构建时所用的一致**（1.1.0）；
  缺库会直接以「Missing or unsupported mandatory dependencies」拒绝启动。
  NeoForge 26.1.2 与 Fabric 1.20.1 两条线**仍然内置**该库，无需另装。
- 1.20.1 的 Mixin 运行时：**Mixin Booster ≥0.1.3** 或 **Sinytra Connector**，**二选一**即可。
- Fabric 1.20.1 需要 **Fabric API** 与 **Puzzles Lib**（后者自带前置 Forge Config API Port）；
  饰品栏用 **Trinkets**（可选兼容 **Accessories**，装了就用、没装照旧）——
  只装 Trinkets 或只装 Accessories 都能玩，**两个都没装才会拒绝启动**。
- **卡牌不再能合成**：22 条卡牌合成配方已移除，卡牌改为通过卡牌商店 / 卡牌交易员 / 骰子与立牌等方式获得。
- 1.3.7 及以前的存档可以直接升级；商店、事件、村民等新内容是新增内容，不会改写旧存档的物品。

## 新增内容

### 商店与村民

- **新增方块「卡牌商店」**：上排 3 个平滑石台阶、中排 3 枚星币、下排 3 个原木合成；换用新的 Blockbench 木质柜台模型
  （带玻璃展示窗），放下时面向放置它的玩家。
- **卡牌商店界面按定稿重做，购买改为「拖拽成交」**：按住货架上的卡牌拖到右下物品栏才算购买 ——
  拖动时卡牌跟随光标，松手在不合法位置即取消、不扣钱；空槽位统一显示为「已售出」样式。
- **商店改为 60 秒轮询**：只有倒计时归零那一刻才换一批卡；沙漏改为 4 档倒计时（不再显示秒数）；
  每一轮只能转账一次、星光兑换一次（买牌不限次）；关闭再打开商店**不再刷新卡牌**。
- **装上「经商」立牌或触发「商店大酬宾」不再整批换牌**：按缺口补上应有的卡位（立牌 +1 张战斗牌、大酬宾 +2 张），

- **商店内可直接「星光兑换」与「转账」**：**2 点星光换 1 枚星币**（无冷却，星光不足会给提示）；
  转账把星币转给同服务器其他在线玩家，单次 **5~20 枚**，带玩家名搜索框与滚动列表。

## 战斗系统重做

- **防御力公式按「玩家 / 生物」分离，并移除护甲 20 点硬上限**：
  玩家 `防御力 = 2 + 护甲值×0.30 + 0.85×盔甲韧性`；生物 `防御力 = 初始防御力 + 护甲值×0.40 + 1.0×盔甲韧性`（最终向下取整）。
  护甲值一律取属性终值 ⇒ 状态效果与其它模组对护甲的修饰先生效，本模组不再二次换算。
- **玩家初始防御力改为 2（1 面盾），原为 4**；初始攻击力不变（空手 1）。
- **防御力点数与护甲值恢复 1:1 折算**：所有「防御力 +X」来源现在真的加 X 点防御力 ——
  旧实现按 `X × 2.0` 加护甲、经系数后只兑现 **0.6X**（怪物 0.8X）。修正后摩托头盔 +2 / +4 / +8、
  黑曜石骰 +10 护甲（= +3 防御力）、多萝西暖意每层 +1 防御力、Jill 每张防御牌 +2 防御力、雷暴将至生物 +2 防御力均按牌面兑现。
  **玩家侧防御力加成相对上一版实际强度 ×1.667（怪物侧 ×1.25）**。
- **防御力取整不再吞点**：护甲取 double 终值，不再经 `getArmorValue()` 向下取整 ——
  此前 26.6667 护甲被截成 26，「防御力 +8」只兑现 +7。骰战结算与穿甲枪取甲同批改用统一入口，保证「显示 = 结算」。
- **生物获得初始攻击力，其近战攻击正式纳入骰战**：敌对生物初始攻击力 4、中立 3、被动 / 友好 0；
  生物攻击力 = 初始攻击力 + 攻击力属性 + 手持武器附魔伤害加成（不再计入已减免过的「本次伤害事件值」）。
- **对骰成立 = 双方都装备骰子**：任一方没有骰子时双方骰点一律按 0 计算，但**骰战公式仍然生效**
  （玩家未装备骰子不再退回原版战斗，只是自身骰点为 0）。
- **战斗牌掷骰改为「单次掷取 + 点数越高越难命中」**：取消「掷 2 次取最大值」，改用递减权重
  （最低点 : 最高点 ≈ 2 : 1）。满值命中率大幅下调：1~3 由 55.6% → 25%、1~6 由 30.6% → 11.8%、
  1~10 由 19% → 6.9%、1~20 由 9.8% → 3.4%；期望值下调 25%~32%。
  名刀·嘎呜切抬高下限照常生效；玻璃骰子 / 上班族立牌「本次点数取最大值」不受影响。
- **防御牌耐久上限 10 → 150**：每次受到一次骰战攻击，装备的所有防御牌各扣 1 点，任一张归零即移除并返还费用；
  远程 / 法术 / 技能等不触发骰战的伤害不消耗防御牌。
- **原版伤害修饰器在骰战下正式生效**：锋利、暴击（下沉中 / 未着地等原版条件，×1.5 只作用于基础段）、
  攻击冷却（`0.2 + 蓄力²×0.8`）、保护与抗性提升（结算后作为乘算因子，玩家→目标与生物→玩家两条路径都生效）全部重建，
  实测与原生一致（锋利 V +42.9%、暴击 +50%、保护 IV 全套 −64%、抗性 II −40%）。
- **伤害跳字改为「最终值」并按伤害类型分色**，位置固定在本次结算处、不再跟随目标跳动。
- **效果牌冷却与「效果本身时长」彻底分离**：出牌即开始冷却（此前只有出牌数打满上限才进入冷却）。
- **治愈计时器与骰神赐福解绑**：改为每 1:00 自动结算（赐福结束后不会再既不衰减也不回血）。
- **符卡-祸的伤害类型改为法术伤害**（原为真伤）。

- **筹码经济调整**：新增筹码配方总开关 `enable_chip_recipes`（默认关闭，关闭时创造栏隐藏四种合成材料）；
  空白筹码战利品箱概率 3% → 1%（埋藏宝藏仍 100%）；筹码商店购买后进入 5:00 冷却，
  冷却中右键空白筹码可投入商店立即解除冷却并 +1 次重抽（每 2:00 限一枚）。
- **四张伤害效果牌（对怪激光 / 对怪板砖 / 轨道炮 / 定向爆破）整体重做**：移除「使用后 1:00 内远程 / 魔法伤害 +N」的增伤，
  改为手持即进入目标选择（敌对 ∪ 中立（宠物除外）∪ 未驯服可驯服生物，不含玩家），确认后直接造成**法术伤害**
  （固定 4 / 6 / 8 / 5 + 效果牌伤害加成）；定向爆破额外对目标 6 格内其他目标造成同样伤害；
  新增 FX 且伤害延迟到 FX 命中时点生效（激光 0.5s 后红色激光线、板砖向头顶投红砖砸落、轨道炮金色信标光束、定向爆破爆开）。
- **各效果牌锁定范围改为逐牌独立**：对怪激光 32 格、对怪板砖 16 格、轨道炮 24 格、定向爆破 24 格、活体书页 32 格、符卡-祸 32 格；
  对友方使用的功能类效果牌统一 16 格。
- **「电击手套」重做**：使用伤害效果牌时消耗 4 层充能，让这张牌本次的远程 / 魔法伤害同时命中目标 3 格内其他目标；
  扩散严格绑定在该次使用上，与定向爆破的 6 格波及各自独立、不互相触发。
- **「安全气囊」追加能力**：无效化致命伤后对施加者反击一次（走统一反击链路）；受到伤害时充能 +1（冷却 15 秒，独立计时）。
- **7 枚既有筹码调整**：银行卡-用不完（未组队时范围收紧到自身 32 格）、大碗炖肉（未组队时 16 格内所有玩家）、
  魔法箭袋（返还「本次使用的那张」牌）、鹰眼瞄具（改为额外攻击伤害）、跃迁引擎（共享冷却 5:00 → 3:00）、
  永动机（赐福补足档 6 → 8、装备期间原版近战攻击冷却 −50%，且不抬高骰战攻击力）、书签（效果牌伤害 +1 → +2）。
- **ATM 机重写**：每次向其他玩家转账，转账双方各额外获得 1 星光与 2 星币。
- **会员推荐信追加能力**：装备期间自己商店内所有卡牌价格恒 −1 星币。
- **诡异骰子不再缩短立牌主动冷却**（保留低点数权重 1-3 由 50% 提升到 75%，以及主动结束后恢复 5 点生命）。
- **合成配方调整**：黄金星盘两条配方并存（星盘×1 + 下界之星×1 无序 / 星盘×3 + 星币×6 有序）；
  星币与星盘新增击杀掉落；16 件立牌 / 筹码配方材料调整；筹码商店配方改为「金锭·星盘·金锭 / 磨制黑石砖块·空白筹码·磨制黑石砖块 / 磨制黑石砖块×3」。
- **星光兑换的「基础值下限」缺陷已修**：银行卡-余额少 / 余额多提供的 +4 / +7 星光现在**能兑换成星币**了
  （此前它们被当成常驻下限，可兑换量恒被扣掉这部分）。
- **模组内所有星币发放统一「优先进钱包」**：海清、邦妮、汉娜、米米、天降之物与大侦探被动等不再直接塞物品栏
  （放不下就掉地上），而是先入钱包余额，钱包关闭才给物品。
