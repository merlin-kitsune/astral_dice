# 星之骰戏 (Astral Dice) 1.3.5 更新日志

已发布：1.3.5 —— 本次是**平衡性调整与问题修复**版本，不含新增物品。主要是五件事：① 效果牌冷却、治愈计时，以及枪匠与怪力侦探两条被动的层数衰减，全部与「骰神赐福」解绑、改为各自独立计时；② 16 件立牌与筹码换料，黄金星盘新增一条配方，星币与星盘新增击杀掉落；③ 枪匠立牌主动 / 被动重写，并新增「七咒之戒」联动；④ 三处判定口径修复（队友识别、第三方近战武器、异常状态的自清限制）；⑤ 修复 1.20.1 打开物品栏必定崩溃。

注意！前置模组 StarEngine Lib 已内嵌进本模组（内嵌 1.0.5），玩家无需再单独安装。如果你的 mods 目录里还放着手动下载的 starengine_lib-*.jar，请删掉它 —— 旧文件会盖掉内嵌的新版库。
注意！1.20.1 的 Mixin 运行时：**Mixin Booster ≥0.1.3** 或 **Sinytra Connector**，**二选一**即可（自 1.3.2-hotfix 起；此前为强制 Mixin Booster）。

## 平衡性调整与质量更新

- **枪匠「弱点识破」与怪力侦探「推理时间」的衰减改为各自独立的 1 分钟计时**：这两条被动此前都挂在「骰神赐福结束」上 —— 每结束一次赐福才扣 1 层，衰减节奏被赐福的起止完全绑死。现改为**每 1 分钟扣 1 层**、与赐福无关；层数归零则效果消失，获得新层数会**重置**这一分钟。枪匠「弱点识破」最多 4 层，每层攻击力 / 防御力 +1、骰点最低值 +1；怪力侦探「推理时间」的层数**死亡不清**。⚠️ 这两个效果不再是「无倒计时」的常驻图标，现在会显示剩余时间。
- **16 件立牌与筹码的合成材料调整**：
  - **立牌 5 件**：上班族立牌 凋灵骷髅头×2 → **黑色染色玻璃×2**；忍者立牌 回响碎片 → **紫水晶碎片**；骇客立牌 幽匿块×2 → **青色混凝土×2**；秘密侦探立牌 信标 → **末地水晶**；机械师立牌 信标×2 → **金锭×2**。
  - **筹码 11 件**：魔法箭袋 回响碎片 → **光灵箭**；高级外设 回响碎片 → **红石比较器**；永动机 下界之星 → **下界合金锭**；原初核心 回响碎片×2 → **下界合金锭×2**、龙首 → **龙息**；魔法秘典 回响碎片 → **末影之眼**；拳击手套-初级 海绵×3 → **白色羊毛×3**；速度轮滑-初级 蓝冰×2 → **冰×2**；肾上腺素-一般 下界之星 → **末影珍珠**、凋零玫瑰×2 → **灵魂沙×2**；会员推荐信 墨囊 → **书**；诅咒之剑 爆裂紫颂果×2 → **灵魂营火×2**；贯穿之铳 回响碎片×2 → **紫水晶碎片×2**。
  - 所有配方的形状与材料组合仍保持全局唯一；手册中机械师立牌的配方描述已同步。
- **效果牌冷却重做：与「效果本身的时长」彻底分离，出牌就开始冷却**：此前只有**出牌数打满上限**才进入冷却，没打满的一轮要等**已出的效果牌效果全部结束**之后才补上一轮冷却 —— 冷却被效果时长拖着走，节奏不可控。现在：**只要出牌就开始冷却，且同一轮内每次出牌都会把冷却重置为 45 秒**（原为 30 秒），即「最后一次出牌之后 45 秒」本轮结束、出牌数归零；打满上限不再单独判定，同样按一次普通出牌重置冷却。**效果时长不再锁住出牌**：冷却归零后即使效果仍在生效，也能立刻开新一轮。拥有「充能」时，效果牌冷却的封顶由 **20 秒改为 30 秒**。⚠️ 未打满一轮的其余规则不变（冷却期间仍可用掉本轮剩余出牌数，出牌数上限的来源也没有改动）。
- **治愈计时器与骰神赐福解绑，改为每 1:00 结算**：此前治愈计时器（30 秒）只在骰神赐福期间运转 —— 赐福一结束，治愈层就既不衰减也不回血。现在改为**完全独立的 1:00 计时器**：触发骰神赐福时仍然结算一次，此后**每 1:00 自动结算一轮**、与赐福无关 —— **先扣掉一半治愈层（向下取整）→ 再由医疗箱补充它提供的固定层数 → 结算后治愈层 > 0 就按 治愈层 ×2 回血并开始下一轮计时，归 0 则移除「治愈」效果**。举例：4 层治愈 + 医疗箱-完备治疗（3 层）⇒ 减半为 2 → +3 = **5 层** ⇒ 回血 **10 点** ⇒ 开始这一轮 1:00 计时。医疗箱的定位不变（获得 / 刷新时的固定加成），只是改在**每次结算之后**补充；医疗箱的物品说明也精简为「**治愈层数 +1 / +3**」（不再描述触发时机）。⚠️ 「治愈」图标只要**层数 > 0 就显示**，且显示的是**剩余的 1:00 倒计时**（不再是 ∞）；只要还有治愈层，计时器就一定在走。
- **教主立牌 tooltip 精简**：「降神」的物品说明与手册同源条目中删去两处多余注释 —— 「（不计入攻击力）」与「（近战或远程，须命中）」，只保留机制本身。
- **枪匠立牌主动 / 被动重写，并新增「七咒之戒」联动**：
  - 主动「弱点反击」：指定一个目标，向其施加「破绽 (2:00)」—— 目标战斗骰点被锁定为 0；**只能对没有「破绽」的目标施加**。
  - 被动：被施加「破绽」的目标攻击你时会**闪避本次攻击并对其发起反击**；每次触发闪避、反击，或主动攻击带「破绽」的目标，获得 1 层「弱点识破」（最多 4 层），每层攻击力 / 防御力 +1、骰点最低值 +1，每分钟减少 1 层。
  - **新增联动**（物品说明的备注区）：佩戴**七咒之戒**并拥有「弱点识破」时 —— **修正第三诅咒：移除护甲降低效果**；**修正第六诅咒：死亡时不再掉落灵魂水晶**（不再减少最大生命值）。需安装提供该物品的联动模组；未安装时这一段不生效。
- **修复与「七咒之戒」相关的联动此前一直静默失效**：此前**骰点七咒减益 −40%、手持启示之证再减 20%、装备倒转之启时完全免疫、命运指引卡的第一诅咒修正**在 1.20.1 上全部没有生效（且没有任何报错提示），相关物品说明的备注区也一直不显示；「恩惠之典」提供的完整免疫则在新版线上同样从未生效。现已全部修复。⚠️ 1.20.1 侧**没有「恩惠之典」**这件物品，因此那条免疫在 1.20.1 上仍不生效。
- **黄金星盘新增一条配方，星币与星盘新增击杀掉落**：
  - **黄金星盘**现在有两条配方并存：**「星盘×1 + 下界之星×1」（无序）** 与 **「星盘×3 + 星币×6」（有序）**。
  - **星币**：**玩家击杀**下列生物时按概率掉落（每次 1 枚）—— 僵尸 / 僵尸猪灵 **1%**、末影人 / 猪灵 **3%**、猪灵蛮兵 **20%**。
  - **星盘**：凋灵 **100% 掉 5 个**、监守者 **100% 掉 3-5 个**、远古守卫者 **100% 掉 1-3 个**、恶魂 **100% 掉 1 个**、凋灵骷髅 / 守卫者 **5% 掉 1 个**；其余怪物仍为 **0.3% 掉 1 个**。
  - ⚠️ 只在**击杀者是玩家**时判定（箭矢 / 投掷物等间接击杀同样算）；星币与星盘两条掉落**互不影响**，同一只怪可以同时掉两者。

## BUG修复

- **忍者立牌的主动技能此前几乎无法释放，现在改为「本轮出牌数上限未达 9 张即可释放」**：上一条冷却改版让**每次出牌都会开始冷却**，而忍者主动「忍术连击」原有三条释放条件的第一条是「效果牌正在冷却中 → 拒绝」—— 这条在旧规则下是合理的（只有打满上限才进冷却），但在新规则下**几乎永远成立**，主动技能形同锁死。现已删除该条件：**只要本轮可出牌数上限还没到 9 张，就能释放，直接 +1 次出牌机会**；另两条条件不变（已达 9 张封顶、或本轮已用过这次 +1 → 拒绝）。
- **修复 1.20.1 打开物品栏必定崩溃**：1.20.1 的「状态效果描述」功能所用的一处注入参数写错，导致该类第一次加载（也就是**打开物品栏**）就抛错 —— **物品栏打不开、客户端直接崩溃**；该问题同时让 1.20.1 的数据生成整体失败。现已修复。
- **修复队友判定完全失效**：此前本模组只把**原版计分板队伍**当作队友 —— 而整合包里的队伍**不一定**走计分板，由**队伍类模组**提供的队伍对这类玩家来说计分板队伍是空的 ⇒ 队友判定完全失效（同一队伍内仍能互相造成伤害、电磁炮仍命中友方）。现在统一识别三种来源（原版计分板、以及各类队伍模组），全模组约 **30 处**「视谁为敌」与 **5 处**队友判定一并改走统一口径（含电磁炮雷击的目标筛选，导弹 / 飞星 / 风扇的波及选目标，以及所有「被敌方攻击才生效」的筹码与立牌）。
  - 顺带修掉一个同源问题：**友方效果此前会扩散到全服** —— 队伍识别失败后，这类玩家被当成「没有队伍」，从而落进「没有队伍 ⇒ 全服玩家都是友方」的兜底，于是大碗炖肉、银行卡「用不完」、奢华大餐、怪力侦探「挚友守护」、人偶师「挚友祝福」等**友方效果实际发给了所有人**。现已一并修复。
  - ⚠️ 如实说明：三个整合包都没有安装「领地与队伍」类模组，该分支属**装上即生效、尚未实机验证**；第三方队伍模组一律走「存在才启用」的守卫，解析失败就永久退回原版计分板口径，不会因对方改版而崩溃。
- **修复 1.20.1 上第三方近战武器无法触发骰神赐福**：此前的判定是**白名单** —— 只有四种原版武器才算近战武器，而绝大多数模组的近战武器（匠魂、灾变等尤其明显）都不是这四种 ⇒ 拿着它们攻击时骰神赐福整类不触发。现已反转为**黑名单**：只排除「空手 / 盾牌 / 工具（镐 / 锹 / 锄，**斧子保留** —— 斧是近战武器）/ 远程武器（弓 / 弩）/ 方块」，其余一律视为可触发的近战武器。
- **修复部分模组的术士等生物反复「喝奶自清效果」导致服务端卡顿**：本模组会拦下对自身异常状态的一切外部清除（牛奶 / 指令等），而会靠喝牛奶自救的法师型 AI 单位因此**反复重试**，服务端随之卡顿。现在增加例外：**目标不是玩家时一律放行**（本模组施加给生物的以减益为主，让它们自己清掉无碍）；玩家侧规则不变。
- **「标记」不再防清理，玩家可以用牛奶清除**：标记此前无法被玩家清除。它的强度由**层数**承载、且是施加给目标的减益，玩家有正当理由想清掉它 ⇒ 现在允许用牛奶或指令清除「标记」。⚠️ 伴随标记的发光仍与标记同寿命（标记还在时不能单独清除），若一次批量清除先处理了发光，发光会留到自然到期（最多 60 秒）。

- **修复手册两页显示原始键名**：手册的「特殊效果」与「教主立牌」各有一页指向的文字此前已被移除，游戏内会把内部键名（`astral_dice.guide.entry.…`）直接显示给玩家。现已删去这两页。
