# 星之骰戏 —— Fabric 1.20.1（移植线）

**版本 `1.3.7-alpha.2`** · alpha 渠道（预发布）· Minecraft 1.20.1 · Fabric

> ⚠️ **这是 Fabric 移植线，不是正式版。** 正式版面向 NeoForge 1.21.1 / Forge 1.20.1 / NeoForge 26.1.2。
> 本线使用**独立版本号**（`-alpha.N`，与 26.1.2 线的 `-beta.N` 同构）⇒ 永不占用正式版的版本号。

## 必需前置

- **Fabric Loader 0.19.5+**
- **Fabric API**（1.20.1 线，0.92.12）
- **StarEngine Lib —— 已内嵌，请勿另行安装。** 通过 Jar-in-Jar 内嵌（`1.0.11`）。
  若 mods 目录里仍有 `starengine_lib-*.jar`，请删除：散装文件优先级高于内嵌件，会被拿来顶替内嵌版本。
- **Puzzles Lib 8.1.33+**（事件桥；请连同它自己的前置 **Forge Config API Port 8.0.3** 一起装）
- **饰品栏提供者 —— Trinkets 3.7.2+ 或 Accessories 1.0.0-beta.48+ 二选一。** Fabric 的 `depends`
  是 AND 语义、无法表达「二选一」，因此两者都只声明为可选；模组在启动时自行检查，
  **只有两者都不在**才会拒绝启动。

可选：**Patchouli**（游戏内手册）。1.20.1 没有 Fabric 版 Bountiful，故本线没有赏金板。

## 本版更新

本线本次是**追平**版本：把此前只在正式线上生效的裁决与修复**集中移植**过来（三条正式线 1.3.7 的内容面本线一并具备），
并同步处理了本线自己的遗漏项。

### 追平正式线（本次集中移植）

- **非武器工具不再算「近战武器攻击」**：拿着**剪刀 / 钓竿 / 打火石 / 刷子**打人时不再触发骰神赐福（骰战）。
- **骰神赐福的「近战武器攻击」判定改回「黑名单」**：只排除**空手 / 盾牌 / 远程专用物品（弓 / 弩 / 弹弓）/ 方块 / 枪械类武器本体 / 非武器工具**，其余一律计入 —— **包括全部挖掘工具（镐 / 锹 / 锄 / 斧）与各模组的武器**。⚠️ 同时具备近战与远程的武器不排除（例：三叉戟）。
- **枪械类武器本体不再能用于近战砸击**（判定逐条取自实物证据）。
- **白泽赐福 / 降神的倒计时改由「任意命中的攻击」启表**：远程攻击（弓 / 弩 / 投掷物）命中同样能启动 2 分钟倒计时（此前只认近战）。
- **效果牌的可选中生物扩大到「未驯服的可驯服生物」**：活体书页与伤害效果牌（含符卡-祸）在原有的敌对目标之上，增加**未驯服的**可驯服生物 —— 狼 / 猫 / 鹦鹉，以及无主的马 / 驴 / 骡 / 骆驼 / 羊驼。⚠️ 已驯服的宠物与已被认领的坐骑仍不可选；村民 / 流浪商人一律排除。
- **探天卫星改口径：「击杀返还随机效果牌」→「效果牌的目标选择距离 +50%」**：佩戴即生效的常驻加成 —— 手持任意**效果牌**时，其目标选择器的锁定范围 **+50%**（16 格 → 24 格）。⚠️ 只作用于效果牌；与调查员立牌主动的「书页射程」**相加**，合计上限 **64 格**。
- **调查员立牌主动追加「书页射程」**：主动技能「活体书页」在原有的「获得 1～2 张活体书页」之外，**追加**一个 **2:00** 的状态「书页射程」—— 持有期间活体书页的使用射程 **+50%**（32 格 → 48 格；同时佩戴探天卫星筹码则 → **64 格**）。⚠️ 状态可见（HUD 图标 + 悬停说明），重复施放只**刷新时长**、不叠加倍率。
- **事件效果改为「队伍 + 64 格」广播**：触发者**已加入队伍** ⇒ 作用于全体队友 ∪ 触发者 64 格内的其他玩家；**无任何队伍** ⇒ 作用于所有无队伍玩家 ∪ 触发者 64 格内所有玩家。事件触发的立牌被动同步按该集合发放；负面结果同样按该范围广播。
- **未装备充能筹码时隐藏充能状态图标**：饰品栏没有任何充能类筹码时，HUD 不再显示「充能」图标；装备回任一充能筹码后立即恢复。
- **常驻（无限时长）状态不再显示超长倒计时**：历史存档里遗留的超长时长，现在会在重新进入世界后自动归一为 **∞**（此前会显示成几万小时）。
- **效果牌会话输入收口**：这类会话现在只接管「释放键 + 收起键」—— **左键 = 释放**、**右键 = 对自身使用 / 收起**、**下蹲 + 右键 = 收起**、**主动技能键 J = 收起**；**鼠标中键 / 侧键**与**卡牌栏键 H** 一律放行。⚠️ 收起后选择器不会自动弹回来，把牌移出主手再握回来即可重新开局。
- **动作栏文本不再与物品名称提示重叠**、淡出时长压缩为 **0.5 秒**；两项动作栏配置移出配置文件（对所有玩家强制生效）。
- 正式线 1.3.7 的其余修复（军火伤害判定、活体书页堆叠、配置文件版本号、死亡点遗留水晶、效果牌会话等）本线一并生效。

### 本线专属

- **客户端装了「现代化 UI」并开启「现代提示框」时，稀有度边框色不再失效**：本线（Fabric 版）与正式线走的是**不同接线**（本线在提示框渲染入口上挂钩子），现由兼容层按档位写入它的描边配色槽、该次渲染结束**立即还原**玩家自己的配置，**不改动它的任何设置**。奇特档借此还能得到**整圈流动的彩虹边框**。配置项 **`modernui_tooltip_frame_compat`**（默认开启）可关闭；未装该界面模组时该层完全空转。
- **清理了本线不存在的联动内容**：本线所在环境没有那些联动模组，相关的手册条目、物品提示与配置项已一并清掉，避免出现指向「装了也没有的东西」的说明。
- **内置前置库升级到 `1.0.11`**（已内嵌，**无需**单独安装）。
- **测试与守门资产**：本线的静态核对（手册键、动作栏通道、注入接线、语言键同步等）已纳入与正式线相同的守门清单，后续改动会自动被拦住。

### BUG修复

- **修复医疗箱筹码可被「反复重登 / 反复过门」无限刷血**：两个医疗箱此前除「真的把筹码装上去时」与「死亡重生后」，还把**每次重新登录**与**每次切换维度**也算作一次完整结算（补点数 → 按当前层数 ×2 回血 → 重置 1 分钟计时器）⇒ 反复重登 / 反复过门即可**无限回血**，层数已满 32 时一次可回 64 点。现按裁决**撤掉这两个时点**：治愈只在「**真的把筹码装上去**」与「**死亡重生后**」触发。⚠️ 与筹码是否还戴在身上无关 —— 戴着筹码重登 / 过门同样不会再触发。
- **修复游戏内手册里两枚立牌的稀有度档位写错**：**人偶师立牌**与**怪力侦探立牌**的物品稀有度**一直是「奇特」**，手册正文却写成了「稀有档」与「史诗档」。现按**以物品为准**的口径把两处手册文字统一改为「**奇特档**」（中 / 英 / 日三语同步）。⚠️ 只改文字：物品稀有度、掉落与配方都不变。
- **修复：本线此前用裸接口清理状态效果时会报错**：清理本模组自己的状态效果时，走了一条会抛异常的内部路径。现已改为按「目标身上是否还有该效果」判定，无效清理直接放行、不再报错，同时**保留**对**外部**清除（喝奶 / 清空效果指令）的拦截能力。
- **修复：手册中多出的第 6 页**已删除，本线手册与正式线**页数与条目完全一致**。
