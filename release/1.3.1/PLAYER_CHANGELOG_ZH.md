# 星之骰戏 Astral Dice 1.3.1 更新日志（玩家版）

> GitHub Release 另外附带第三条线 **26.1.2 (NeoForge)** 的构建产物，后缀 `+neoforge_26.1.2`（版本号带 `-beta`，功能与发布线对等）。

**一句话概括**：「敌对目标」的判定放宽 —— 中立生物不再需要先被你打一下才算敌对（**未驯服的狼现在直接算敌对目标**）；贯穿之铳不再要求「已使用伤害效果牌」，普通箭矢也能吃到加成；并修掉试验假人选不中 / 打不到的问题。

## ⚖️ 平衡与体验调整

### 敌对目标的判定放宽：中立生物不再需要「先被打一下」

- **「敌对目标」的判定口径改写为「敌对生物 ∪ 中立生物（宠物除外）」**：此前中立生物**必须已被激怒**才算敌对目标 —— 于是一头没被激怒的狼、一只没被激怒的铁傀儡 / 北极熊 / 蜜蜂在你眼里都「不算敌对」，只有你**先挨它们一下**、让它们进入 20~39 秒的激怒状态后才会变成敌对目标。现在改为**中立生物一律计入，只排除已驯服的宠物**。
- ⚠️ **实测影响面**：原版同时具备「中立生物」与「可驯服」两种身份的只有**狼**，所以这条实际等价于「**未驯服的狼现在算敌对目标，驯服后不算**」。
- 该口径是**全局**的：「敌对目标」的唯一入口在前置库 `StarEngine Lib` 里，因此**所有**依赖它的效果一并生效 —— 骰神赐福的触发、法伤加成、目标选择器的可选中判定（准星过滤 / 半径高亮 / 服务端确认）、电磁炮落雷选目标等。

### 贯穿之铳：判定条件与忍术飞镖完全对齐

- **贯穿之铳移除「伤害效果牌生效时」这一前提**：原先它还要求「身上带着伤害类效果牌生效」（对怪激光 / 对怪板砖 / 轨道炮 / 定向爆破四个效果之一，或本次命中就是活体书页的法伤），于是**先打出去的普通箭矢 / 投掷物 / 联动模组法术**拿不到加成。现改为：**只要佩戴贯穿之铳并对目标造成远程 / 魔法伤害，即额外增加目标防御力点数的伤害**。
- **目标判定也已与忍术飞镖完全对齐 —— 不再限制「必须是敌对目标」**：旧判据比实际闸门窄，导致**非同队但从未攻击过你的玩家**、以及**未带原版「中立生物」标记的中立怪（山羊 / 羊驼 / 狐狸等）**只吃忍术飞镖、不吃贯穿之铳。现在两者判定**完全同形**，目标范围一律由法伤链的统一闸门决定。
- 物品说明与手册条目已同步删去「已使用伤害效果牌」前提与「敌对目标」限定。

### 四张伤害牌与电击手套的说明也改齐了

- **对怪激光 / 对怪板砖 / 轨道炮 / 定向爆破 与 电击手套**的效果说明，原先写「**对敌对目标**造成的远程和魔法伤害 +N」，但实现上它们**根本不判定目标** —— 只要效果在身，打谁都有加成。文案比实现窄，容易误以为「对中立生物无效」。现已统一改为以「远程和魔法伤害」开头，并按实现写明范围波及的对象是「其他目标」。

### 几项数值调整

- **星币锤**：每次进入骰神赐福消耗的星币由 **3 → 6**。
- **智能手表**：物品栏卡牌补充阈值由 **10 → 6 张**（更容易维持手牌）。
- **标靶**：触发骰神赐福后的标记不再落到**你正在攻击的那只**身上，改为选中**它之外**距离最近的目标 —— 标记终于可以用来「另立一个靶子」。
- **魔法箭袋**：改为**必须先用过一张伤害效果牌**（对怪激光 / 对怪板砖 / 轨道炮 / 定向爆破 / 活体书页），并在对**已有标记**的目标造成远程或法术伤害后，返还第一张使用的效果牌并施加 1 层标记（每 30 秒只触发一次）。活体书页本身也算伤害效果牌 —— 但同样要先「用过一张」。

## 🐛 问题修复

### 试验假人现在可以被选中、被打中了

- **试验假人（`dummmmmmy` 训练人偶）现在被永远视为敌对目标**：此前它既不属于「敌对生物」、也不会被激怒，所以任何「需要敌对目标」的效果都把它排除在外 —— 最直接的后果是**活体书页根本选不中它，也就打不到它**（想拿它试伤害都不行）。现已从底层修正：试验假人在**所有**「敌对目标」判定中都算敌对 —— 骰神赐福能正常触发、法伤加成会照常计算、目标选择器也能正常选中它。

### 枪匠立牌：中立目标现在也吃「弱点识破」

- 1.21.1 / 1.20.1 两条线此前把枪匠被动限定成「**普通敌对生物**」，于是**狼 / 铁傀儡 / 北极熊 / 蜜蜂、山羊 / 羊驼**这类目标即使身上带着「破绽」，打死也拿不到「弱点识破」层数（同一次攻击的骰神赐福倒是照常触发）。现两线已与 26.1.2 对齐：触发条件与骰神赐福完全一致。
- 顺带说明：枪匠**主动**的目标选择本身就是「敌对 + 中立（已驯服宠物除外）+ 试验假人」，**一直可以选**中立目标。

### 四处「波及 / 加成」打不到同类目标的问题

- 定向爆破与电击手套的**范围波及**、大当家立牌的**溅射**、以及骰战「调查阶段增益」，此前用的是更窄的敌对判据 —— 于是一个**没主动打过你的玩家**、**Boss**、或**会反击但原版没标「中立」的动物**，作为主目标能吃到加成，站旁边的同类却吃不到波及。现已统一到与骰神赐福、忍术飞镖、贯穿之铳**同一套闸门**。

### 电击手套的范围波及不再误伤自己

- **电击手套与定向爆破**：范围波及此前会**把你自己也算进目标** —— 近距离攻击时会被自己的波及伤害打到。现已修正：波及只会命中**其他目标**，不再包含施法者本人。

### 电击手套的范围波及不再误伤自己

- **电击手套与定向爆破**：范围波及此前会**把你自己也算进目标** —— 近距离攻击时会被自己的波及伤害打到。现已修正：波及只会命中**其他目标**，不再包含施法者本人。

### 怪力侦探的投掷伤害不再被法伤加成放大

- **怪力侦探立牌「怪力投掷」**：落地那 2（+5）点伤害此前是**按法伤结算**的 —— 会被忍术飞镖、贯穿之铳、紫晶骰子、标记喷罐、魔法箭袋以及伤害效果牌的加成一路放大，还可能触发电击手套的范围波及。现已改用**独立的技能类伤害**：只结算它自己的固定点数（仍然无视护甲）。并且与真伤一样**穿透受击无敌帧** —— 不会被目标的短暂无敌吞掉。


### 说明与显示

- **友情徽章 / 大碗炖肉**：删掉说明里的括号注释（去重规则、算作「友方生物」的范围）—— 这些是实现细节，玩家不需要知道。
- **普通瞄具 / 鹰眼瞄具**：说明文字已精简（删去冗余的限定语），行为不变。
- **探天卫星**：说明里的括号改成逗号，句式统一。
- **复仇之戟**：删掉「每类只触发一次」与「不叠加」的说明。
- **速度轮滑（初 / 中 / 高级）**：物品说明里那个 **`%` 号不再掉色**（此前会掉成行底色，看起来像没被高亮）。

## 📌 安装要求

- ✅ **本版起，前置模组 StarEngine Lib 已内嵌进本模组 —— 玩家无需再单独安装**：产物内自带一份 `starengine_lib`（内嵌于 `META-INF/jarjar/`），由加载器在启动时自动载入。
- ⚠️ **内嵌版本 = `1.0.3`，兼容区间 `[1.0.3,2.0)`**（与 `mods.toml` 里声明的前置区间同源）；**请不要**再单独放置 `starengine_lib-*.jar` —— 加载器按 modId 去重时优先采用它，更旧的那份会盖掉内嵌库。库的源码仓库：<https://github.com/merlin-kitsune/starengine_lib>
- **其它前置**：Curios API（**1.20.1 另外强制需要 Mixin Booster**）。
- **26.1.2 线**：前置 Curios API **15+**；该线**无 Iron's Spells 'n Spellbooks 联动**。
- **可选联动**：帕秋莉手册（规则书）、Bountiful 赏金板。
- **版本互通门槛（联机）**：客户端与服务端必须为**同一二号位版本**（`1.3.x` ↔ `1.3.y` 可互通）。跨版本连接会被**明确拒绝并给出提示**，而不是静默失败。
