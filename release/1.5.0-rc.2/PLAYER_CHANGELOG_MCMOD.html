[h1=星之骰戏 (Astral Dice) 1.5.0-rc.2 更新日志（预发布 Beta）]

本版覆盖自 1.3.7 以来的全部改动，是一次大版本跳跃。要点：

  • 商店体系：新增方块「卡牌商店」与「筹码商店」、村民职业「卡牌交易员」与「筹码商人」、方块「抽奖盒」。
  • 事件体系：12 个事件 + 事件卡动画 + 大侦探立牌的「事件选择界面」。
  • 内容：7 张新立牌（超天酱 / 地雷女 / 修女 / 大肥鱼 / 多萝西 / 调酒师 / 怪力乱神；立牌总数 24 → 31）、两张新效果牌（路障 / 强化拒止，后者另有物品形态）、6 枚新筹码（筹码池 61 → 67）。
  • 平衡：10 张既有立牌、16 枚既有筹码与诡异骰子有机制 / 数值调整；两处「获得即触发」的口径统一（去掉「合成」）。
  • 战斗系统重做：防御公式按玩家 / 生物分离、防御力加成改为 1:1 折算、生物攻击纳入骰战、伤害下限改为攻击力的 15%、战斗牌改为单次递减掷骰、防御牌耐久 150、原版伤害修饰器回归、伤害跳字按类型分色。
  • 界面：战斗数值条（防御力条 / 攻击力条）、Jade 联动、商店冷却倒计时。
  • 许可：源代码改为 GPL-3.0-only。

本次预发布只提供两个构建：astral_dice-1.5.0-rc.2+neoforge_1.21.1.jar（Minecraft 1.21.1 / NeoForge）与 astral_dice-1.5.0-rc.2+forge_1.20.1.jar（Minecraft 1.20.1 / Forge）。其它平台线不在本次预发布范围内。

[h2=一、本版（rc.2）相对 rc.1 的变化]

下面各章是自 1.3.7 起的全量说明；如果你已经玩过 1.5.0-rc.1，只需看本节。

  • 多萝西立牌 · 主动：给队友的 +1 点攻击力改为独立状态效果【交际花】（图标 = 多萝西立牌贴图；与该立牌的被动同名，但两者不是同一件事）—— 固定 1:00、从获得时开始计时，与施放者的主动窗口解耦（窗口结束不再回收，晚进圈的队友也能吃满 1:00），重复获得只刷新时长、不叠层（攻击力始终 +1）；同时删掉「每 10 秒才结算一次」的间隔（每个友方玩家每个窗口本就只结算一次）。多萝西自身 +1 攻/人（可叠加、计时结束清除）与被动「每 10 秒回 2 血」均未改动。
  • 调酒师立牌 · 主动：治疗效果改为按效果牌张数叠加 —— 此前无论选几张效果牌都只回固定 2 点，现为每张效果牌 2 点（1 张 2 点 / 2 张 4 点 / 3 张 6 点），与同一技能的「攻击牌 +2 攻/张、防御牌 +2 防/张」口径一致；每张牌各自结算一次治疗（3 张 = 3 次 = 6 点），多萝西「温暖」因此按治疗次数叠层（3 张 = +3 层），按次数结算的下游（赵赐福溢出 / 治疗失效）也各结算三次。
  • 立牌中文名订正（纯文案，机制不变）：熊猫人 → 上班族（Padman Sign）、提尔 → 教主（Cult Leader Sign）、酒保 → 调酒师（Bartender Sign）。
[h2=二、安装与前置（必读）]
  • 本版起 StarEngine 不再内嵌：发货 jar 里已删除内嵌库（不再包含 META-INF/jarjar/），前置库 StarEngine（modId 为 starengine，版本 1.1.0）改为独立前置，必须自行下载对应加载器的 starengine-<加载器>-1.1.0.jar 放进 mods。版本需与本体构建时一致；缺库会以「Missing or unsupported mandatory dependencies」拒绝启动，看到这句话先检查库 jar 是否漏装。
  • 1.20.1 的 Mixin 运行时需要 Mixin Booster 0.1.3 或更高版本，或 Sinytra Connector，二选一即可。
  • 卡牌不再能合成：22 条卡牌合成配方已移除，卡牌改为通过卡牌商店 / 卡牌交易员 / 骰子与立牌等方式获得。
  • 1.3.7 及以前的存档可以直接升级；商店、事件、村民等新内容都是新增内容，不会改写旧存档里的物品。
[h2=三、新增内容] [h3=1. 卡牌商店（新方块）]
  • 合成：上排 3 个平滑石台阶、中排 3 枚星币、下排 3 个原木（3×3 工作台）。放下后右键打开，无消耗、无冷却。
  • 货架：基础上架 3 张卡牌（同一批不会出现两张同名卡），基础价 3 枚星币；每格买走后显示「已售出」；同一批卡持续有效，只有 60 秒轮询归零那一刻才换一批（关掉再开不刷新）。
  • 经商立牌联动：同队有人佩戴「经商立牌」时额外上架 1 张战斗牌，且每张牌各有 10% 概率降价为 1 枚星币。
  • 蓄力牌只有在骰子星级 ≥ 2 时才会出现在货架。
  • 界面：带玻璃展示窗的木质柜台（Blockbench 模型，碰撞与选中框随模型收紧）；品红标题「卡牌商店」居中；6 个卡框，卡面填满、卡名完整显示（过长自动缩字号）；折扣牌在卡面右下角标出；左侧按钮为星光兑换星币，中间按钮为转账（星币少于 5 枚或冷却中灰化），沙漏按冷却进度显示；左下为星币余额条，右下为玩家物品栏。
  • 购买为「拖拽成交」：按住货架上的卡牌拖到右下物品栏才算购买，拖动时卡牌跟随光标、原卡位显示「已售出」底图；没拖到物品栏就自动移回（不扣钱）；星币不足时拖不动（红字提示所需星币）；落点格被占用会提示换一格。空槽位统一显示「已售出」样式。
  • 购得即视为「获得」：会正常触发维生素药丸的治愈与教主立牌的狐光层数；购买成功播放钱包音效。
  • 界面细节：按钮改为纯图标（说明移到悬停提示）；转账页面完全独立（打开转账时商店内容一律不渲染）；转账金额为 4 档按钮（5 / 10 / 15 / 20），带玩家名搜索框、滚动列表、每行显示头像 + 名字 + 当前余额，选中行有粉色箭头指示；转账成功后自动退回商店主界面，同一轮内不能再次转账。
[h3=2. 商店内的「星光兑换」与「转账」]
  • 星光兑换：2 点星光 = 1 枚星币，无冷却，每轮一次（星光不足时给提示）。这是「经商立牌」原主动「套现」迁入商店后的入口。
  • 转账：把星币转给同服务器其他在线玩家，单次 5~20 枚，每次转账后 60 秒冷却（与商店换牌共用同一个计时器，掉线也照算）；目标在确认前离线会自动刷新名单并提示重选；每轮一次。佩戴「经商立牌」的玩家转账成功后，自己货架上顺序第一张未售出的卡牌会被强制降到 1 星币。
[h3=3. 筹码商店（新方块）]
  • 合成：金锭 · 星盘 · 金锭 / 磨制黑石砖块 · 空白筹码 · 磨制黑石砖块 / 磨制黑石砖块 ×3（3×3 有序）。
  • 一次给出 3 个筹码格，从你尚未拥有的筹码中按权重抽取（同一批不重复），每格显示该筹码自己的图标，三格同价。
  • 价格：从 10 枚星币起步，同一个玩家每买过一枚就 +5、上限 100（刷新或重开都不重置）。
  • 品质按骰子星级加权：0–1 星为稀有 60% / 史诗 37% / 传奇 3%；2 星为 40% / 45% / 15%；3 星为 25% / 50% / 25%。
  • 流派权重：你已装备的同流派筹码会让该流派更容易被抽到（每枚 +60%）；上一次买下的类别在本批第一格权重 ×2（第二、三格 ×1.25）。
  • 刷新：初始 3 次、上限 5 次，用掉第一次刷新后才开始计时，每 30 分钟恢复 1 次（不在店里也照常累积）；次数用尽时刷新按钮只闪红、不再发包。已集齐全部筹码或物品栏没有空位时无法开店（会给提示）。
  • 购买：买下后筹码直接进物品栏并关闭界面；购买后商店进入 5:00 冷却；冷却中右键空白筹码可把它投入商店——立即解除冷却并 +1 次重抽，每 2:00 限一枚。物品栏满时照常成交：扣款、次数 +1、候选重抽都照常，装不下的那枚掉在脚边并提示；创造模式下按原版规则直接被吞掉（不掉落、无提示）。
  • 界面：花费栏为星币小图标 + 金额；刷新只显示剩余次数；候选图标 24×24；候选格脚下按品质画三色描边环（稀有蓝 / 史诗紫 / 传奇金）；过长筹码名左右滚动；被选中的格子名称改黑字；鼠标悬停候选筹码（筹码格或其下方标签都算命中）即弹 tooltip。商店不绘制标题；没有任何折扣路径（「会员推荐信」的减价只作用于卡牌商店）。
[h3=4. 村民职业]
  • 卡牌交易员（以卡牌商店方块为工作方块）：新手 / 学徒上架稀有卡（2–6 绿宝石），老手 / 专家上架史诗卡，专家 / 大师上架传奇卡（最高 20 绿宝石），价格按卡牌数值强度微调；老手级起可用 1 绿宝石换 1 星币，佩戴绿宝石骰子时不显示这条兑换。
  • 筹码商人（以筹码商店方块为工作方块）：售卖筹码，品质与等级绑定——L1 稀有 / L2 稀有 + 史诗 / L3 史诗 / L4 史诗 + 传奇 / L5 传奇，出现权重 6 / 3 / 2；老手级同样解锁「1 绿宝石 → 1 星币」（绿宝石骰子时隐藏）。
  • 两个职业各用专用工作方块标签（原版共享标签仍然保留，村民照旧能发现并认领工作站），职业查看类模组不再把两家的方块显示成同一份。
[h3=5. 抽奖盒（原「事件抽奖盒」）]
  • 右键花 5 星币买一张抽奖牌，每 5:00 限购一次（余额不足或冷却中通过 ActionBar 红字拒绝）；换用新贴图与新配方（星盘 · 星币 · 星盘 / 星币 · 钻石骰子 · 星币 / 星盘 · 星币 · 星盘），手册附配方页。
  • 物品「事件抽奖牌」更名为「奇怪的问号」并换新图标（使用后从事件池随机抽一条事件，生存模式消耗 1 张）。
  • 卡牌商店 / 筹码商店 / 抽奖盒三个方块改为不可堆叠。
[h3=6. 交易类筹码调整]
  • 会员推荐信追加能力：装备期间自己商店内所有卡牌价格恒 −1 星币；与经商立牌的 10% 降价可以叠加，最低 0 星币（0 价直接拿走、不扣星币）。
  • ATM 机重写：每次向其他玩家转账时，转账双方各额外获得 1 星光与 2 星币（仅转账发起者装备时触发）。原「装备时获得 1 星光」与「星光兑换 +40%」两项能力已移除。
  • 星光兑换的「基础值下限」缺陷已修：银行卡-余额少 / 余额多提供的 +4 / +7 星光现在能正常兑换成星币（此前被当作装备期间的常驻下限，可兑换量恒被扣掉这部分）。
[h3=7. 事件体系（重写）]
  • 每个事件现在有统一的名称、图标、类型（正面 / 中性 / 负面，只影响文本颜色）、阶级、作用范围与可注册的触发方式，并支持每个事件独立计时器（重复触发会重置）。
  • 12 个事件（作用范围 = 触发者 64 格 ∪ 团队全体）：
  • 红温警告：攻击力 +5，3:00，正面。
  • 疾行：迅捷 II，2:00。
  • 雷暴将至：1 张随机卡；范围内敌对生物攻击力 +2、防御力 +2，2:00；夜间且附近有该状态的玩家时，敌对生物自然刷新数量 ×2。
  • 取长补短：受影响玩家里生命值最低者 +8、最高者 −8；先治疗、1 秒后再伤害。
  • 商店大酬宾：商店出售卡牌 +2，5:00。
  • 手牌抹杀：随机丢一张卡，卡牌直接消失、不掉落。
  • 天崩地裂：立即 4 点伤害。
  • 天降之物：1 张随机卡 + 3 星币，星币直接进钱包，正面。
  • 天使降临：4 点治疗。
  • 问题外卖：立即 2 点伤害 + 中毒 / 饥饿各 0:15 + 15 秒内治疗无效，负面。
  • 拥挤通道：所有玩家被传送到触发者位置，中性。
  • 战斗爽：2 张「攻击-特大」。
  • 状态指示器：红温警告 / 雷暴将至 / 问题外卖会在效果栏显示同名图标；问题外卖生效期间原生中毒 / 饥饿图标由专用指示器取代。红温警告的攻击力加成与雷暴将至的攻 / 防加成走本模组战斗模型，且是瞬态（死亡或重登即消失）。
  • 事件卡动画：事件触发时屏幕正中弹出事件卡——0.2 秒淡入放大 → 1.0 秒停留 → 0.2 秒缩小淡出；上格事件图、下格事件名（按类型染色：正面绿 / 中性黄 / 负面红）+ 计时器。弹卡后约 1.9 秒（38 刻）才真正结算（28 刻可见动画 + 10 刻缓冲），计时器与效果、音效同刻登记；卡片文字与卡面同步淡出，不再残留。
  • 事件音效：event_fade_in（弹卡）、event_heal（治疗类）、event_damage（伤害类）、event_poisoning（问题外卖）、event_transport（拥挤通道）、event_bonus（天降之物）。
  • 大侦探立牌主动重做为「事件选择界面」：使用后弹出居中面板，从当前事件池随机抽 2 个事件（可出现相同事件、可任意正 / 负 / 中性组合）；鼠标指向卡片换成高亮底图，单击选中并保持，必须点确认才触发；顶部为 15 秒倒计时，超时 / 死亡 / 退出时强制触发第一个选项（已确认的选择不会被覆盖）。按下技能键那一刻立即播放主动音效，确认时不再播放，并当刻关闭界面直接进入事件流程。
  • 秘密侦探的「调查阶段」：只有击杀「隐匿调查」目标才会提升一阶（先按当前阶级触发、再升阶），4 张分阶图标接线（调查阶段 I / II / III / 真相揭露），所有阶级持续时间均为 1:00；队内多名秘密侦探各自独立；已被施加「隐匿调查」的目标不能再次被任何人施加；击杀时除「真相揭露」阶级外，事件只作用于施加调查的那名秘密侦探与该击杀者。该事件只有在队内存在秘密侦探时才可能被抽到。
  • 两个抽事件入口：物品「奇怪的问号」与方块「抽奖盒」。
  • 模组内所有星币发放统一「优先进钱包」：海清、邦妮、汉娜、米米、天降之物与大侦探被动等不再直接塞物品栏（放不下就掉地上），而是先入钱包余额，钱包关闭时才给物品。
[h3=8. 新立牌（7 张，立牌总数 24 → 31）]

1.5.0 一次性加入 7 张立牌：奇特 5 张（超天酱 / 地雷女 / 调酒师 / 多萝西 / 大肥鱼）、稀有 1 张（修女）、史诗 1 张（怪力乱神）。配方见 JEI 与手册。

超天酱立牌（奇特）

  • 主动「网络天使」：立即获得（1 + 粉丝数）枚星币（最多 10 枚）；粉丝数 ≥3 时恢复全满、≥9 时友方玩家各得 3 星币（有队伍覆盖全队，无队伍覆盖 64 格内其他玩家）。
  • 被动「小天使请安」：使你攻击或攻击你的目标成为「粉丝」（永久状态），粉丝攻击你时伤害 −1。
  • 备注「一心同体」：队内有地雷女时该被动同样对其生效（她的粉丝计数归你）。粉丝数上限 10、跨死亡保留、卸下立牌清零。

地雷女立牌（奇特）

  • 主动「感情过量摄入」：立即恢复「爱」层数 ×2 的生命值，并获得 1:00 移动速度 +20%；时间结束后扣除 4 层「爱」且「爱」上限 +1（最多 32）。
  • 被动「无法承受的爱」：基础防御 6 点；受到敌对攻击每 30 秒 +1 层「爱」（装备时初始 2 层、上限初始 4 层）；每层「爱」攻击力 +1、防御力 −1（最低 0）；「爱」超过 4 层时每超出 1 层 +1 最大生命值。
  • 备注「一心同体」：队内有超天酱时她获得 6 点基础防御，且她受伤时队内所有地雷女各 +1 层「爱」。「爱」跨死亡保留、卸下立牌清零。

修女立牌（稀有）

  • 主动「铁处女」：免疫任何伤害与负面效果，持续 0:30；若处于骰神赐福期间且被动已失效，立即恢复被动效果。
  • 被动「鼓起勇气」：每次触发骰神赐福时获得 5 点攻击力；期间受到超过 10 点伤害则移除该加成；骰神赐福结束后始终移除。

[h2=四、战斗系统重做]
  • 防御力公式按玩家 / 生物分离（均向下取整）：
  • 玩家：2 + 护甲 × 0.30 + 0.85 × 韧性（原为 4 + 护甲 × 0.30 + 0.85 × 韧性）——初始防御 4 → 2。
  • 生物：生物初始防御 + 护甲 × 0.40 + 1.0 × 韧性（原为护甲 × 0.40）。
  • 生物初始防御：敌对 4 / 中立 3 / 被动 0（被动生物不再享受和敌对生物一样的护甲效率）。
  • 防御类加成改为 1:1 折算：银行卡、立牌、筹码等「防御力 +X」现在每 1 点直接等于 1 点防御；旧实现按 2.0 倍护甲再乘 0.30 / 0.40 的系数折算，导致玩家侧只兑现 0.6 倍、怪物侧 0.8 倍——实际强度相比旧版是玩家 ×1.667、生物 ×1.25，所以这个预发布里玩家会觉得「变脆了」，这是刻意的平衡调整。
  • 不吞小数：防御力按 double 终值参与结算，2 + 护甲 × 0.30 里的 0.6 不再被取整丢掉。
  • 骰点为零时公式仍生效：双方任一方未装备骰子时骰点按 0 计，但防御力 / 攻击力公式照常参与对拼（不再整段跳过）。
  • 伤害下限：当防御点 ≥ 攻击点时，最终伤害改为 max(1, 攻击力 × 15%)（此前固定 1 点）；减免类效果（磨刀石、怪力侦探等）在最终伤害之后结算，允许把伤害扣到 0。
  • 战斗牌改为单次递减掷骰（同一目标连续命中时骰面上限逐次 −1，技能或换目标后重置）：满值命中率 1~3 面 55.6% → 25%、1~6 面 30.6% → 11.8%、1~10 面 19% → 6.9%、1~20 面 9.8% → 3.4%，期望输出整体下降 25~32%，长战斗里的「越打越强」收益被压平。
  • 防御牌耐久 10 → 150（配合上面的 1:1 折算，防御牌的作用从「一次性小盾」变成真正的一层护甲）。
  • 骰神赐福只能由玩家主动近战触发：生物攻击玩家、以及防御方掷骰都不再触发。
  • 原版伤害修饰器回归：锋利 V +42.9%、暴击 +50%、保护 IV −64%、抗性 II −40%——此前本模组的重做把原版加成丢了，这次接回原版管线后再叠加骰战结果。
  • 伤害跳字重做：数值 = 本次实际扣血（管线终值），不再显示「理论伤害」；红 = 攻击力与伤害加成（含溅射 / 波及 / 反击），绿 = 法术与技能伤害；同一 tick、同一目标、同色的多段伤害合并成一条（例：一发激光连穿三个目标各显示各自一条，同级联的三段攻击只显示合计一条）；只发给造成伤害的玩家本人（没有玩家归属时发给受击者）；位置在结算那一刻由服务端固定、不跟随目标移动（避免追随箭头），并带 ±30° 随机扩散，多段伤害的数字不再完全重叠。
  • 其它流程：卡牌堆叠 64 → 16；效果牌冷却出牌即开始计时（同一轮内每次出牌都会重置 45 秒、充能封顶 30 秒）；治愈计时器改为每 1:00 独立结算一次（不再与赐福周期耦合）。

  • 诡异骰子：不再提供「立牌主动技能冷却时间减半」；改为「主动技能结束（三个互斥出口）时 +5 治愈点数」，并保留「更容易骰出低点数（1–3 点权重 50% → 75%）」。
  • 攻击牌 / 防御牌：移除「掷 2 次取最大值」，改为单次掷骰并逐次递减（详见第三部分）。
  • 四张伤害效果牌（对怪激光 4 / 对怪板砖 6 / 轨道炮 8 / 定向爆破 5）：由「持续 1:00 的远程与魔法伤害加成」改为「瞄准目标、延迟 0.5 秒结算的固定点数魔法伤害」，并各自配了 FX。
  • 掉落与产出：星币击杀掉落为 僵尸 / 僵尸猪灵 1%、末影人 / 猪灵 3%、猪灵蛮兵 20%；星盘按目标分档：凋灵 5、监守者 3–5、远古守卫者 1–3、恶鬼 1、凋灵骷髅 / 守卫者 5%、其余 0.3%。
  • 获取途径：黄金星盘改为双配方；16 件物品的配方换料（上班族、忍者、骇客、秘密侦探、机械师五张卡与 11 枚筹码）；空白筹码埋藏概率 3% → 1%（「埋藏宝藏」本身仍是 100%）。
  • 创造栏 / JEI 排序：筹码按稀有度升序排列（组顺序 星光 → 治愈 → 标记 → 充能 → 无流派 不变，组内 稀有 → 史诗 → 传奇）；强化拒止物品形态不再列入创造栏与 JEI（仍注册、仍能正常获得与使用；开「显示隐藏物品」才看得到）。
  • 筹码配方总开关：配置项 enable_chip_recipes 默认关闭；关闭只影响筹码的合成配方；再生试剂 / 导电线材 / 星币尘 / 标记涂料四种材料与所有筹码（含空白筹码）仍始终显示在创造栏与 JEI（2026-10-18 起解绑该开关：立牌合成需要这些材料）。

  • 1.20.1 启动直接失败（Forge）：本体的 StarEngine 版本区间原先写成了星号，Maven 把它解析成空区间，导致 containsVersion() 恒为 false、所有 1.20.1 玩家必现「Missing or unsupported mandatory dependencies」，现已改为显式区间。
