# 星之骰戏 Astral Dice 1.2.1 更新日志（玩家版）

> 适用范围：**1.2.0 → 1.2.1**，同时适用于 1.21.1 (NeoForge) 与 1.20.1 (Forge)。版本号后缀：`+neoforge_1.21.1` / `+forge_1.20.1`。
> 本文件是玩家侧发布说明，与 `CHANGELOG_ZH.md` 的 1.2.1 小节一一对应（不含工程 / 工具条目）。

**一句话概括**：新增 `/astralparty` 管理员调试命令；电磁炮与法伤改走真伤、敌对目标判定全服统一；立牌主动技能改为「可用 → 生效中 → 冷却」三态；并修掉出牌永久锁死、忍者旧出牌银行、tooltip 恒显示 0 等一批问题。

## ✨ 新增内容

### 管理员调试命令

- **新增 `/astralparty` 管理员调试命令（4 个子命令 + 2 个别名，仅 OP 权限等级 2 可用）**：
  - `cleareffect`：清除**全部 33 个**本模组效果。
  - `clearcardeffect`：只清**效果牌施加的效果**（共 **9 个**）。
  - `resetcardlock`：重置出牌限制的**出牌数**（含全部「每轮一次」标记）与**出牌冷却**；别名 `resetcardcolddown`（原拼写）与 `resetcardcooldown`（拼写正确版）与主命令**共用同一套实现**。
  - `dump`：**只读**子命令，一条命令把关键状态按固定格式输出到玩家聊天栏与 `latest.log` 日志文件（便于事后排查）；**不改变任何状态**。
  - 四个子命令都**只在服务端**注册与执行，**随 jar 发布**，没有测试专用的隐藏开关。目标参数可选（`@a` / 玩家名）；执行者不是玩家且未给参数、或选择器解析不出玩家时，会返回可读的失败提示而不是报错。
  - 能力边界严格限定为「重置 / 清除本模组自身状态」：不给予任何资源（物品 / 卡牌 / 筹码 / 星币 / 星光 / 治愈 / 最大生命），也没有「把任意数值设成任意值」的通用写入；默认只作用于执行者，只有明确给了玩家选择器才作用于该玩家（绝不隐式作用于全体），也不触碰原版或其它模组的玩家状态（例如光灵箭施加的发光）。

## ⚖️ 平衡与体验调整

### 电磁炮与法伤真伤化

- **电磁炮**：雷击伤害改为 **5 + 本次攻击（骰战最终）伤害 × 50%**（下限 **5** 点；此前为「本次攻击伤害的 50%、下限 5 点」）。雷击的**伤害类型改为真伤**——**无视护甲值与盔甲韧性**，保护附魔与抗性提升仍会减免。雷击的**命中范围收窄为「仅敌对生物与已被激怒的中立生物（如被攻击后的末影人）」**：非敌对目标**不受伤、不转化、不触发事件、也不进成就**（原版闪电对这些实体是照打不误的）；方块着火、避雷针等世界行为按原版保留。**你自己、友方宠物、中立动物、盔甲架等一律整段取消**，并且**由你驯养的宠物也被排除**（例如被激怒的自己养的狼，不会再挨自己的雷击）。**你视为敌对的玩家**（非同队伍、且曾主动攻击过落雷来源玩家）同样会被落雷命中，与其它范围效果口径一致。原版闪电的其余行为（点火、闪电苦力怕、僵尸猪灵 / 女巫转化）一律不变，并补齐了该真伤类型的死亡消息文案（中英双语）。
- **伤害效果牌（法伤）改走真伤**：远程 / 魔法命中的效果牌加成不再并进本次伤害（并进去会连武器伤害一起吃护甲值 / 盔甲韧性 / 保护附魔的减免），改为单独结算——**只有效果牌那部分穿甲**，基础武器伤害照旧。定向爆破与电击手套的范围波及伤害同步改真伤。

### 敌对判定、标记上限与真伤结算

- **统一「敌对目标」判定口径**：口径 = **敌对生物 ∪ 已被激怒的中立生物**。两版本各 **24 处**玩法判据点全部改用统一入口（贯穿之铳门、定向爆破 / 电击手套 / 大当家溅射 / 标靶 / 手持风扇小大的范围筛选、调查阶段增益、嘲讽反击，以及诅咒之剑 / 电流剑 / 智能手表 / 探天卫星 / 手电筒 / 肾上腺素 / 电磁炮的触发与击杀计数、史莱姆「治愈粘液」的缓慢、骇客的解除隐身与被动类型、秘密侦探「关键线索」）。此前只有电磁炮雷击一处做了激怒判定，**被激怒的狼 / 铁傀儡 / 北极熊 / 蜜蜂**在其余各处一律被漏掉；末影人 / 僵尸猪灵 / 猪灵等本身就是敌对生物，一直计入，且**平静（未激怒）时同样算敌对目标**（本次维持现状）。顺带修正 **5 处**绕过统一口径的历史写法（定向爆破范围伤害、标靶最近敌对目标、大当家溅射、骇客解除隐身、秘密侦探关键线索）；**战利品掉落池**（怪物类 **0.3%** 掉星盘）属掉落口径、与「敌对目标」无关，刻意不改。
- **标记层数上限由 16 层提高到 32 层**：标记的可叠加上限现为**固定常量 32**（原为配置项，该配置项已删除）。层数数字**仅在 2~10 层时**显示在物品栏效果面板的标签与悬浮提示上，**11 层及以上不再显示数字**（原版 HUD 只画图标、不显示层数）。两版本一致。
- **真伤结算不再被无敌帧削减或吞掉**：把真伤登记进「不受无敌帧限制」后，原版刚写好的 **20 tick** 无敌帧不再对它生效。受益者：效果牌法伤加成、定向爆破与电击手套的范围波及、大当家溅射——它们都以嵌套伤害结算，恰好落在无敌帧内，**加成不超过上一次受伤值**时会被整段丢弃（实测：箭 1 点 + 激光 +4 只落地 3 点）。**副作用如实写明**：电磁炮雷击走的是**同一种**真伤类型，因此也一并穿透无敌帧；而反击注入与绯红骰 / 王之力自伤走的**不是**该类型，行为不变。
- **敌对玩家规则（全局）**：非同队伍、且**主动攻击过你**的玩家一律视为敌对目标，故**大当家溅射与电磁炮落雷现在也会对这类玩家造成同样效果**。**不记录**本模组内部的范围 / 波及结算与反击注入，也不记录自伤与任一侧非玩家目标的情形；玩家**死亡**（晚于保命方的「取消死亡」）、死亡重生克隆与**退出服务器**时清除该立场（作为攻击方与作为受害方的记录一并清除，不持久化、服务器重启即清空）。

### 大当家立牌

- **大当家立牌·溅射改为被动单次效果**：触发骰神赐福时若养精蓄锐已满 **5 层**，则**消耗 2 层**（替代常规的 -1 层，且这 2 层在溅射**真正生效时**才扣除），并在**本次攻击伤害定稿后立即**对**目标及其 6 格范围内（含目标本身）**的敌对目标造成本次攻击伤害 **88%**（**下限 5 点**）的伤害；伤害类型为**真伤**（**无视护甲值与盔甲韧性**，保护附魔与抗性提升仍会减免），命中时附带爆炸粒子与音效（**仅视觉表现**）、**不破坏方块**、**无友伤**（只命中敌对目标）。同时**修复溅射对主目标不生效**的缺陷：此前主目标会在无敌帧内把溅射整段丢弃（实机：主靶只掉近战 3 点、5 点溅射凭空消失）；现只对主目标临时清零无敌帧再结算，实测主靶恢复为「近战 + 溅射」全额。旧实现（主动消耗 2 层 → 下次赐福期间每次攻击持续扩散）已移除，**主动技能不再消耗层数**。

### 出牌轮收尾

- **出牌轮收尾口径**：本轮**所有效果计时器结束后**同样进入一轮 **30 秒**冷却——判据为「出牌数未达上限、且剩余被锁时长为 0」，时长与「打满上限」复用同一口径。但**不作废剩余出牌数**：该分支不把计数补齐到当轮上限，冷却期间仍可继续出牌，冷却到期后计数归零。「打满上限即进入冷却」的规则不变；另规定一轮冷却**已在跑**时不会被冷却期间的补牌重启或延长（否则补得越晚冷却越长、持续出牌时周期永不结束）。同时**统一了「轮次完全重置」的清理项**：除一次性出牌数加成 / 可口糖果 / 探天卫星 / 活体书页本周期累计外，**电击手套本周期已武装的法伤扩散也统一解除**（下个周期可重新武装）——此前忍者宽限期满走的强制重置不解除武装，两条「轮次完全重置」路径的清理口径不等价。

### 立牌主动技能三态

- **立牌主动技能改为「三态」：可用 → 锁定（生效中）→ 冷却 → 可用**：此前主动技能只有「可用 / 冷却」两态，凡施加带时长效果的主动一按下即起冷却，效果还在跑时冷却已经走完，可以立即再次触发。现细化为三态——主动触发成功后，若本次**确实施加了带时长效果 / 自身计时器**，则进入**锁定（生效中）**态：必须等**该技能施加的全部计时器跑完**才允许进入主动技能冷却，锁定期内**按键无效**并提示「主动技能生效中！」；锁定结束**必起冷却、无空档**。不施加带时长效果的主动与三类待命技能（占星师 / 秘密侦探 / 枪匠）行为与改动前逐字一致（仍为「触发 / 释放即起冷却」）。
- **需上锁的 7 个立牌 / 不上锁的 9 个立牌**：**上锁 7 个**——经商、扫地机、护法、大侦探（**仅实际施加带时长效果的分支**，只发物品的分支不起锁、直接进冷却）、吸血鬼、骇客、大当家；这些立牌的主动会施加自身侧带时长效果（或写入自身侧到期刻），触发后进入锁定态。**不上锁 9 个**及原因：看板 / 调查员 / 上班族**纯发牌**（不产生任何计时器）；史莱姆 / 肉弹战车**仅目标侧效果**（敌对目标身上的缓慢 / 嘲讽，不代表施加者身上的主动仍在生效中）；占星师 / 秘密侦探 / 枪匠**仅 30 秒待命窗口**——判定**不算**本技能的计时器（待命期是「等待选目标的窗口」而非技能效果时长，且超时未命中不消耗冷却的现行设计必须保持，故不进入锁定态）；忍者**无任何计时器**，改由下一条专用规则接管。
- **锁定期间使用的减免改为累计入池（不再改当前冷却）**：锁定态的主动**不写**主动冷却的结束时刻，故「命运的指引」「加急加快」（扫地机被动）与史莱姆 **-10 秒**这三类减免在此期间无处可改。现改为：锁定期间使用这些减免时**累计入池**，等锁定结束、**真正进入冷却时一次性抵扣**——**实际冷却 = 起冷却时的实际基准 − 累计池**（结果不小于 0）；抵扣后池归零。基准仍在**锁定开始时**就写定，故各减免方读取的数值与算式不变。非锁定态的减免行为与改动前逐字一致（仍直接改冷却结束时刻）。
- **忍者立牌专用：锁定跟随出牌周期 + 1:00 宽限保险**：忍者主动「忍术连击」本身不施加任何计时器（只把当前出牌轮出牌数 +1），故触发后**不立即进入冷却**，而是让**锁定跟随效果牌周期**——**冷却从「该轮出牌状态完全重置那一刻」开始**。另设**宽限期 1:00**（自触发主动起算）：期内**自始至终未出任何效果牌** ⇒ **强制重置出牌状态并让主动技能进入冷却**；一旦出过效果牌 ⇒ 宽限保险失效、改为遵循出牌周期自然重置。
- **电流核心筹码：锁定态严格禁用**：主动技能处于锁定（生效中）时，电流核心的「耗充能立即完成冷却」**不可触发、不消耗充能**，并给出与三态化**同一条**提示「主动技能生效中！」；该筹码**仅在真实冷却态**可耗充能立即完成冷却，完成后仍需再次按键释放技能（既有行为不变）。

### 安全气囊

- **安全气囊：保命范围重定为「无视无敌」的致死伤害（虚空伤害例外）**：此前「无视无敌的致死伤害」不参与保命，现在 `/kill` 与其它模组的真伤等**无视无敌的致死伤害同样会被安全气囊无效化**；**但虚空伤害例外**——虚空击杀优先级最高，气囊与磨刀石的不可击杀保护一律不阻止。致命判定统一按**吸收（黄心）之后**：1.21.1 在吸收之前判定，故按「伤害 − 吸收量」（下限 0）换算后与生命值比较；1.20.1 在吸收之后判定，天然达标、不做换算。保留**死亡事件兜底**（优先级早于末影骰子的死亡处理）：若致死绕过了伤害管线（如外部直接把血量清零），气囊同样取消死亡并把血量抬到 1。其余口径不变——仍按最终伤害判定、仍消耗 **6 层充能**并进入 **1:00** 冷却，充能不足或冷却中不生效；tooltip 与帕秋莉手册保持「无视无敌的致死伤害同样有效（如指令 /kill）」的通用写法（未逐字写明虚空例外，本批不改文案）。

## 🐛 问题修复

### 伤害与保命

- 修复**末影骰子「雨中 / 水下受伤 +40%」在骰战路径上被整段丢弃**：此前这 +40% 会被骰战自算的最终伤害覆盖式写入，于是被赐福玩家被近战命中时这 +40% 凭空消失。现改为「受击侧伤害修饰器」（实时判定、不落地状态：脱下末影骰或离开雨 / 水立即失效），由受击侧的唯一应用点求值一次并登记该次伤害的倍率，骰战路径只**搬运**同一倍率、不二次消费——**一次伤害事件恰好应用一次 ×1.4**。两版本按各自减免阶段生效（1.21.1 护甲后、1.20.1 护甲前）这一**既有差异保持不变**。**另修掉 1.20.1 的重复消费（×1.96）**：该版的比值捕获点**晚于**受击侧修饰器的应用点，捕获到的比值已含本次 ×1.4 并经骰战内置因子再应用一次，若骰战路径再搬运一次倍率就是 ×1.96，故该情形不再搬运（1.21.1 的捕获点早于应用点，比值不含该倍率，无需此规则）。
- 修复**电击手套 3 格范围波及伤害的基准跨版本不一致（1.20.1 偏大）**：1.21.1 以**护甲 + 附魔减免之后**的值为基准，1.20.1 却以**护甲前**的原始值做范围波及，于是带甲目标周围被多打一截。现把 1.20.1 的法伤主链路改到与 1.21.1 相同的阶段（护甲之后），读取处的语义随之对齐。残余差异（平台固有）：目标带**吸收（黄心）**时两侧基准仍有差（1.20.1 在吸收之后派发、1.21.1 在吸收之前），普通目标无吸收故实际影响可忽略。

### 立牌与出牌

- 修复**效果牌出牌状态机永久锁死（外部汇报的严重 BUG）**：出牌数达到当轮上限后，若**上限在周期中途下降**——卸下大背包 / 忍术飞镖、卸下可口糖果 / 探天卫星、命运的指引到期等都会让上限**实时变小**——「已打满」判定就会永久成立，而清理逻辑又因「没有冷却在跑」直接提前返回、永不清理出牌数，于是**效果牌永久不可用**，界面停在「本轮出牌数已用完！剩余冷却 0 秒」，且摘掉任何筹码 / 立牌都无法恢复（出牌数与物品无关，外部汇报的「无法清除」正是这一条）。修复补齐了状态机不变量：① 发现「计数已达上限却无冷却」时按既定口径**补上这一轮冷却**，使其在一轮冷却后正常清零；② 周期边界同样识别该状态（无论调用方如何都不会留下死状态）；③ 上限增加防御性下界（异常为负时不得让上限退化为 0 / 负数）。同时 **长按右键不再连续出牌**：现在同一次按住只出第一张，**必须松开再按**才算新的出牌意图，且只对手持效果牌时生效，不影响放置方块 / 进食 / 弓箭等其它右键行为。另：活体书页的「本周期出牌数累计 +1」补上封顶（只推到封顶 **9** 即可），避免无界累加。
- 修复**忍者立牌主动「忍术连击」残留旧出牌银行**：完全重写为**一次性**效果——只把**当前出牌轮**的可出牌数 **+1**，不累积、不跨轮、不产生常驻状态；旧的出牌银行与相关实现**全部删除**。释放前置改为三条：① **效果牌冷却进行中**不释放；② 出牌上限已达封顶 **9 张**不释放；③ 本轮已授予过 +1 不释放——三者均**不消耗**主动技能冷却，并各自给出 ActionBar 提示；立牌装卸**不再回收**已授予的 +1。**忍者触发后不立即进入冷却**（锁定跟随出牌周期、并有 **1:00** 宽限保险，见上文三态条目），故「释放成功」不再等于「立即起冷却」。同时**清除忍者残留的计数效果**：HUD 不会再出现「忍者立牌出牌」效果图标（效果总数 **34 → 33**），魔法秘典的计数不受影响。两处被动计数改为在 tooltip 中显示：忍者立牌新增「已出效果牌：N/3」计数器，魔法秘典筹码新增**同文案**计数器——两者是**两套代码、各读自己的数据**，互不影响。tooltip 由**客户端**渲染，故这两个数值同时补齐了同步（1.20.1 的同步键 **23 → 25**）——此前二者均未同步，客户端读到的永远是默认值 **0**，tooltip 会**恒显示 0/3**。
- 修复**立牌主动技能冷却的减免基准不统一（枪匠被过度减免、加急加快会「免费立即完成」）**：新增「本次冷却实际使用的最大冷却」记录，减免方一律读它——「命运的指引」与扫地机被动「加急加快」不再按 180 秒基准减免，电流核心「立即完成冷却」的充能定价分母也改读实际基准（记录缺失时回退旧行为）。**数值对照（枪匠主动冷却 120 秒；诡异骰子减半；任意充能 -20%）**：① 枪匠单独（实际最大 **120 秒**）：加急加快后剩余 **30 秒 → 60 秒**，命运指引后 **30 秒 → 60 秒**；② 枪匠 + 诡异骰子（实际最大 **60 秒**）：加急加快 **0 秒（免费立即完成）→ 30 秒**，命运指引 **15 秒 → 30 秒**；③ 枪匠 + 诡异 + 充能（实际最大 **48 秒**）：加急加快 **0 秒（免费立即完成）→ 24 秒**，命运指引 **12 秒 → 24 秒**。另修两处哨兵值缺陷：史莱姆「细胞分裂」的主动冷却 **-10 秒**不再把结束时刻写成「无冷却」的 0（改为夹底到当前时刻）；命运指引与加急加快在冷却**已过期**时不再视为「冷却中」而写入新值。**锁定（生效中）期间**这三类减免一律改为累计入池、不改当前冷却（见上文三态条目），非锁定态的算式与判据逐字不变。
- 修复**立牌「待命」残留计时器导致主动技能永不冷却（可无限连按）**：冷却门槛此前只看原始计时器数值，而「超时清除」写在各立牌自己的 tick 里——立牌离身后（死亡掉落）该 tick 不再运行，残留的正计时器让门槛**永远成立**，于是该玩家**任何立牌**的主动技能都不再进入冷却。现改为**状态与计时器分离**：冷却门槛只看状态，待命超时改由**玩家级 tick**（与立牌是否还在饰品槽无关）把状态与计时器归零、并移除对应的「待命」提示效果；占星师 / 秘密侦探 / 枪匠三处的重复超时清除随之删除。

### 电磁炮、星盘与兑换

- **电磁炮在无可命中目标时白扣充能**：旧流程「攻击立即扣 **6** 层充能并进入 **1:00** 冷却，1 秒后才判断目标」会在被攻击目标于这 1 秒内死亡、且周围 3 格无其它敌对目标时白白消耗；现改为**充能与冷却都推迟到雷击真正落下的那一刻结算**，取不到任何可命中的敌对目标（或充能已被其它筹码花掉）时**整次触发作废**——不消耗充能、不进入冷却、不生成雷击。同时加固雷击调度：到期条目先整体摘出队列再逐条处理（避免处理期间新增条目引发的中断），单条雷击失败只记警告并跳过，不再中断服务端 tick 循环。
- 修复 **1.20.1 的星盘战利品修饰符全部失效**（宝箱与生物掉落里的星盘注入形同不存在）：该版本并没有可用的内置注入类型，而全部 **13** 个掉落修饰文件都沿用了不适用的类型名，于是被逐条判为解码失败、注入列表为空。现按该平台的正确基类补一个等价实现并使用自己的命名空间（不与其它模组冲突），**13** 个文件的类型名同步改写；附加表刻意不重复跑一遍全局修饰符，避免被下游修饰符改两次。校验：实机注入条目数为 **13**，且地牢宝箱连滚 **400** 次产出星盘约 **20** 枚（单次 **5%**；修复前为 **0**），日志不再出现解码失败（1.21.1 侧未改动）。
- 修复**星光兑换可以白嫖**：星光兑换现在只允许兑换**超过基础值**的部分（银行卡等提供的下限不可兑换出去），并按**实际扣除量**发币（取扣除前后的余额差值）——此前「净扣 0 仍按请求量发币」，佩银行卡时经商「套现」每 3 分钟白拿星币的路径由此关闭。无实际扣除时返回 0，经商主动随之**整个作废**（不进入主动技能冷却、不发随机增益、也不触发技能响应事件）并给出 ActionBar 提示。

### 存档、同步与死亡处理

- 修复 **1.20.1 缺少 Forge 版本门槛**（低于 Forge **47.4.10** 的环境也能加载本模组，随后报错）：加载器门槛此前只卡到 **47.0.0**。现改为由配置自动派生两个区间——语言提供者用**主系列区间** `[47,48)`，Forge 强制依赖用**精确区间** `[47.4.10,48)`。低于 47.4.10 的环境现在会在依赖校验阶段被拒绝（提示 `Missing or unsupported mandatory dependencies: forge`），合规环境正常加载。**为什么精确区间不能写进语言提供者**：该提供者的版本号就是 Forge 主系列号（47），写 `[47.4.10,48)` 会被判定为版本不符并**直接拒绝加载本模组**（已实机验证）。校验：构建产物两处分别为 `[47,48)` 与 `[47.4.10,48)`；实测旧区间接受 47.0.0 / 47.3.0 / 47.4.9（BUG 复现），新区间三者全部拒绝，47.4.10 / 47.4.23 / 47.5.0 / 47.9.9 通过、48.0.0 拒绝；并实机启动 1.20.1 客户端确认模组正常加载。
- 修复 **tooltip 数值恒为客户端默认值 0 的三处同步缺陷**：① 调查员立牌「活体书页伤害增加：+N」；② 肉弹战车立牌「获得生命值：+N」；③ 骇客立牌 tooltip 最下方的「攻击力 / 防御力加成」行（它经**间接**读取，不是直接调用，极易漏检）。三者此前均**未同步**，而这些数值全部由客户端渲染 → 恒显示 **0**（骇客被动 **+3** 同样恒为 0）。现按同一口径补齐同步（1.20.1 的同步键 **25 → 28**）。修正后双版本 tooltip 涉及的全部数值（含间接读取链）均为已同步，无遗漏。
- 修复**调查员 / 忍者立牌「效果牌伤害加成」的「死亡保留」从未真正生效**：1.2.0 起更新日志与代码注释均称这两项死亡保留，但实际没有任何标记让它随死亡复制，于是玩家一死，已累计的活体书页数与忍者伤害增益即归零（表现为数值与法伤加成凭空掉回初始值，与文档及更新日志不符）。现按记录的本意补齐：**这两项现在真的随死亡保留**。**但仅靠克隆复制不够**：默认规则（不保留物品栏）下死亡会把立牌从饰品槽丢出，Curios 的轮询随即触发立牌离身清理、把这两项清零，且**早于**克隆复制——于是「死亡保留」只在保留物品栏（测试世界）或死亡时未佩戴立牌时才成立，真实生存世界仍会归零。现补上第二层机制（死亡清理时暂存、克隆与重生时回写），双版本同步。同时明确一条口径：**这两项加成只在佩戴对应立牌时生效**——死亡掉落立牌后累计值虽保留但不再加成，直至重新装备。
- 修复 **1.20.1 客户端附件缓存跨会话残留、tooltip 显示上一局的旧值**：客户端缓存是**静态字段**（不随客户端玩家实体重建），而全量同步快照只下发「服务端存在原值」的键——上一世界 / 上一会话的残留值会一直生效到该键被再次写入。实测路径：世界 A 用过 **5** 张活体书页 → 换到新世界（服务端已是 **0**）时客户端 tooltip 仍显示 **+5**（与上一条「未同步恒为 0」是两类不同的错误：值本身是对的，但显示的是旧世界的值）。现双管齐下：① 全量同步快照改为对**全部 28 个同步键**下发，服务端缺失的键下发**显式默认值**，覆盖登录 / 重生 / 切换维度三种入口（重生时新玩家数据为空，正是此前漏发的情形）；② 新增客户端会话清理，断线时清空缓存，兜住「此后不再写该键」的离线残留。仅 1.20.1 需要（1.21.1 用原生附件、客户端数据随加入世界重建）。
- 修复**末影骰子保命时把不该清的效果也清掉了（两版本统一为只清有害效果）**：1.21.1 此前用的清除范围默认为**全部效果**——实际会把增益一并清掉；1.20.1 的「清空全部效果」同理。现改为遍历当前效果、只移除**有害效果**（两版本同步），「先把血量设为 1、再清效果」的既有顺序保持不变。**另补充**：把**发光**额外加入显式清理白名单——标记由标记系统与发光**一同施加、同一寿命**，而发光属中性、不在有害之列，只清有害会残留发光轮廓，与既有「标记仍存在时发光不得被单独清除」的口径不一致；为免误伤本模组之外的来源（原版光灵箭、指令、其它模组），该追加**只在玩家确实带着本模组标记时生效**（有标记时该效果实例即「标记随身的那份」，随标记一同消失）。本模组自身效果仍由既有守卫保留——牛奶 / 蜂蜜 / 指令清除等外部清除一律被拦下。
- 修复**死亡清理的优先级与清单**：死亡清理由默认优先级降为**最低优先级**——保命方（末影骰子、安全气囊）取消死亡后，被救回的玩家不再被按死亡清理（此前同优先级顺序反转时，被救回的玩家仍会走玻璃骰子销毁与计数清空）。同时删除清单里 **23 项**「把本来就回默认的数值写 0 / false / 空串」的无效项，只保留带真实副作用的调用（静态暂存表、物品数据、移除效果、阻止效果被重新施加）。并**补齐**写在立牌物品上的累计值在死亡时的归零：与护法剑气同款，新增**扫地机**与**上班族**的移动累计攻防值清除——死亡掉落走 Curios 的掉落处理、不回调离身清理，此前没有任何路径会归零它们。
- 修复**饰品装卸清理的参数绑定错误**：官方卸下回调的第二个参数是**将要占用槽位的物品**（玩家真正卸下时为空），第三个才是**被卸下的那件饰品**；旧实现把第二个当成被卸下的物品，后果是①**换装（A → B）时被误判为「仍在槽位」而整段跳过清理**；②真正卸下时把清理写到了错误的物品上（部分路径下即空物品）。现改为只按正确参数判定（第三个参数为空 ⇒ 无可清理对象；第二个参数为空、或与被卸下者**不是同一物品** ⇒ 真实移除 ⇒ 清理；**同一物品 ⇒ 视为槽位内数据变化引起的回调 ⇒ 不清理**），并把清理对象固定为**被卸下的那件**，立牌 / 筹码 / 骰子三处同步。已知残留缺口（与改动前一致）：玩家主动销毁饰品的路径按「不清理」处理。
- 修复**《恋的规则书》在玩家死亡后重登会再发一本**：发放守卫此前**不在「随死亡保留」集合内**，于是玩家死亡后新实体上该标记回默认值，而发放挂在登录事件 ⇒ **再次登录必再发一本**（测试世界保留物品栏时书仍在背包，重复尤为明显），与「仅在玩家第一次进入世界发放一次、此后任何情况下都不再自动发放」的口径不符。现把该标记纳入死亡保留（**保留集合现为 3 项**）。发放时机、**首次加入赠书开关**（类初始化读一次、改配置须重启生效）与「发放前只查守卫、**不查背包**」的语义均未改动。

### 文案与描述文本

- 修复**英文描述两处缺失信息（与中文、实机不一致）**：① 占星师主动技能的英文 tooltip 写作 "the first target you hit"，漏掉中文与实现都具备的「符合骰神赐福触发条件」——命中目标需要满足该条件；② 帕秋莉手册中大侦探条目里中文列有「获得滋养 (2:00)（需安装农夫乐事）」，英文只写 "gain Nourishment (2:00)"，漏掉安装前提（同条 tooltip 英文早已写 "(Farmer's Delight only)"）。两处均已补齐，与中文和 tooltip 口径一致。
