# 星之骰戏 (Astral Dice) 1.5.0-rc.7 玩家更新日志

已发布：1.5.0-rc.7（**预发布 / Beta**）—— 这是在上一预发布基础上的一次**修复性**更新：玩法与内容没有变化，只修一个会让服务器整崩的 bug：

- **崩服修复**：属性表里没有攻击力属性的生物（典型是暮色森林的九头蛇）近战命中玩家时，服务端会抛 `IllegalArgumentException: Can't find attribute minecraft:generic.attack_damage` 并以 `Ticking entity` 整崩；重启后再被它命中一次就复发，形成进不去世界的崩溃循环。本版后不再崩，且这类生物的攻击仍然照常参与骰战结算。
- **普通生物不变**：僵尸这类正常生物的伤害数值与前面的预发布完全一致，不用重新适应手感。
- **已真机验证（NeoForge 1.21.1 单线）**：先复现原崩溃、再验证已修；同批对照的普通生物读数与改前一致。

> **本预发布只提供两个构建**：`astral_dice-1.5.0-rc.7+neoforge_1.21.1.jar`（Minecraft 1.21.1 / NeoForge）
> 与 `astral_dice-1.5.0-rc.7+forge_1.20.1.jar`（Minecraft 1.20.1 / Forge）。其它平台线本版不提供构建。

## BUG 修复

- **生物近战命中玩家时整崩（`Ticking entity`）**：有一类生物的**属性表里根本没有攻击力属性**（`minecraft:generic.attack_damage`）—— 它们的伤害在脚本里写死、从不读属性表，暮色森林的九头蛇（`twilightforest:hydra`）就是这样出招的。
  这类生物一旦近战命中玩家，旧代码会无条件去读那个不存在的属性，直接抛
  `IllegalArgumentException: Can't find attribute minecraft:generic.attack_damage`，服务端按 `Ticking entity` 整崩；
  **重启后只要再被它命中一次就再崩一次**，于是形成崩溃循环（`Description: Ticking entity`，世界进不去）。
  本版改为：属性缺席时不再读它，改用**这一击实际打出的伤害**当它的攻击力参与骰战结算 —— 崩溃消失，这类生物的伤害仍按真正打出的量算，不会被吞成 0。
- **普通生物的数值逐点不变**：有攻击力属性的生物照旧走原口径，骰战结果与旧版一致（僵尸一类生物的伤害读数与改前相同）。
- **真机验证（固定普通难度，`neoforge-1.21.1` 单线）**：同样条件下九头蛇一次命中让玩家掉 **46** 点血，同批对照的僵尸仍是 **5** 点 —— 说明修复没有把普通生物一起改强或改弱。

## 已知问题与设计说明

- **本批修复只在 `neoforge-1.21.1` 上做过真机验证**：`forge-1.20.1` / `neoforge-26.1.2` / `fabric-1.20.1` 三条线**未做真机验证**（源码已按同一口径同步、编译通过，但没有实机复现与对照读数）。
- **P1 两条线本版不更新**：`neoforge-26.1.2` 与 `fabric-1.20.1` 不提供本版构建，对玩家而言仍停在原来的版本状态；本版只交付 P0 的两条线（`neoforge-1.21.1` / `forge-1.20.1`）。
- **1.20.1 上的已知偏差**：对身上带**伤害吸收（黄心）**的玩家，这类无属性生物的攻击点数会**偏低估一档** —— 1.20.1 的结算钩子拿不到护甲前的原始伤害，能取到的量已经被吸收扣过一遍，属平台限制（已登记），不是可选的取值口径。普通（无黄心）情况下数值正常。
- **本版仍是预发布（Beta）**：功能与数值与上一预发布相同，数值仍在调整中，欢迎反馈。

## 安装与前置（必读）

- **`StarEngine` 必须与本 mod 成对安装**（NeoForge 1.21.1 / Forge 1.20.1）：发货 jar **不内嵌**库（包内已无 `META-INF/jarjar/`），
  `mods` 里需要另外放对应加载器的 `starengine-<加载器>-1.1.0.jar`。本体对库的**硬前置区间是 `[1.1.0, 2.0.0)`**：
  低于 1.1.0 或高到 2.0.0 都会被拒。缺库或版本不符会以「Missing or unsupported mandatory dependencies」拒绝启动 —— 看到这句话先检查库 jar 是否漏装、版本是否对不上。
- 1.20.1 的 Mixin 运行时：**Mixin Booster ≥0.1.3** 或 **Sinytra Connector**，**二选一**即可。
- **不需要改配置、不需要迁移存档**：本次只改战斗结算里的一个取值分支，配置项与存档格式都没动，旧存档直接进。
- **如果你曾因这个崩溃循环进不去世界**：升级本版即可 —— 不用删实体、不用开新档，那只生物从此也不会再把服务器带崩。
- 两个 P0 交付线：**`neoforge-1.21.1`** 与 **`forge-1.20.1`**；P1 两条线本版不提供构建。
