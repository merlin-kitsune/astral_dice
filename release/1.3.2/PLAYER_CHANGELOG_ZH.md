## 🎁 新增内容

### 初次冒险赠礼：你在这个存档的第一个战利品箱，必定开出 1 个骰子

- 玩家进入一个新世界、开启自己的**第一个战利品箱子**时，箱中**必定**出现 **1 个骰子** —— 优先放进**随机空槽**；若整箱已被战利品塞满（装了很多模组的整合包里很常见），则**强行顶掉一个随机槽位**，保证骰子一定到手。
- **同一玩家在同一存档只享受一次**：记录存在玩家存档里，所以**换存档会重新计数**，而**死亡重生或跨维度不会重复发放**。
- 只对「战利品箱子」生效（箱子、陷阱箱、木桶、潜影盒、漏斗与运输矿车；丛林神庙发射器除外）—— **你自己摆放的箱子不会触发**。

### 新增自定义音效

- **技能生效音**：主动技能生效时播放（进入目标选择器也算）。
- **玻璃骰子破碎**：佩戴玻璃骰子时死亡播放。
- **轨道轰炸命中**：在**命中位置**播放。
- **效果牌使用音**统一为一条（**狂暴 / 王之力 / 岿然不动** 三张仍是各自的专属音）。
- **活体书页 与 符卡·祸** 的命中音换成新素材：按**本次造成的伤害**分档 —— 伤害**小于 8** 用常规打击音，**不小于 8** 换成重击音，并在**被击中位置**播放。

### 机械师立牌（传奇）：轨道轰炸 + 物资补充

- 主动「**轨道轰炸**」：指定一个敌对目标，随后**按「快捷栏 → 副手 → 背包」的顺序取用卡牌**（**取至基础总伤害达单轮上限即停，多余卡牌保留**），对指定目标及其**周围 12 格**范围进行轨道轰炸。每取用 **2 张**卡牌增加 **1 次**轰炸次数（**上限 10 次**）；单次轰炸命中范围内**随机 1 个怪物**并造成 **2 点**基础伤害，另加**等于所取用战斗牌费用总和**的额外伤害。
- 被动「**物资补充**」：物品栏手牌数**不足 6 张**时，每 **1:00** 自动获得 **1 张**随机卡牌。
- 单次释放取用 **6 张及以上**卡牌时触发「**精准打击**」，使被命中目标受到的轨道轰炸伤害**每层 +1**，**永久持续直到其死亡**（该加伤**独立于**单次 80 / 单轮 800 上限）。

## ⚖️ 平衡与体验调整

### 战利品箱：空白筹码更容易出，玻璃骰子开始掉落

- **空白筹码**：在**埋藏的宝藏**中仍是 **100% 必出**；其余战利品箱新增 **3%** 概率掉落 —— 此前除埋藏宝藏外**没有任何箱子**会出空白筹码。
- **玻璃骰子**（T1 黄金档）现在会从战利品箱开出：普通箱 **2%**、**末地城**宝箱 **5%**，每次 **1 个**。此前战利品箱**完全不出任何骰子**（骰子只能靠合成与赏金奖励池获得）。
- 两者与「初次冒险赠礼」**互不影响**：首箱仍 **100%** 额外给 1 个基础骰子，玻璃骰子按自身概率独立判定，**可能同时出现**在同一个箱子里。

### 机械师立牌的「轨道轰炸」数值调整

- 战斗牌费用加成改为 **1 费 = 1 点伤害**（原 1 费 = 2 点）；目标选择器半径 **32 格**（原 16 格）。
- **单次轰炸伤害上限 80 点**、**单轮（一次释放）总输出上限 800 点**。
- **改为「按伤害上限取牌」**：释放主动技能时不再**烧光全部手牌**，而是按 **快捷栏 → 副手 → 背包** 的顺序逐张取用，**基础总伤害一旦达到单轮 800 点上限就立即停手，多余卡牌留在物品栏里**；若把全部卡牌取完仍达不到上限（例如清一色 0 费牌），则照旧全部用掉。轰炸次数与伤害都只按**实际取用**的卡牌计算。
- **「精准打击」改为真·无限时长，且加伤独立计算**：在目标死亡前**永久有效**；其**每层 +1 的加伤另算**，**不占用**单次 80 / 单轮 800 的额度（额度只按基础部分记账）。副作用（有意）：基础额度用尽后，剩余轰炸仍会以纯「精准打击」加伤造成少量伤害。

### 星币锤：门槛上调、消耗变高、加成封顶

- 启动门槛改为**持有至少 32 枚星币**（原为「超过 20 枚」）。
- 每次进入骰神赐福消耗 **18 枚**星币（原 6 枚）。
- 攻击伤害加成**上限 100**（仍按持有星币总数的 **30%** 计算，超出部分不再累加）。

### 绿洲女王：释放主动技能需要 3 个空格（改回旧值）

- 释放主动技能所需的主物品栏空格由 **2** 改回 **3** —— 与「每次固定发放 2 张战斗牌 + 1 张效果牌」对齐。
- 空格不足时**拒绝释放**，且**不消耗冷却、不施加效果**；提示文案同步改为「**需要 3 个空格**」。

### 白泽赐福 / 降神：改为固定 2:00，且「首次近战命中才开始计时」

- 这两个效果此前都是「持续到受术者的**下一次骰神赐福结束**」，时长会跟着骰神赐福的节奏漂移，骰神赐福一结算就可能**当场失效**。现在统一改为**固定 2:00**，且**计时在被施加者首次进行合格近战攻击后才开始**。
- 效果本身**立即生效**（施加当下就已经起作用），但那 **2:00** 的倒计时**要等第一次近战命中才开始走**。
- 合格攻击 = **近战武器攻击**（剑 / 斧 / 重锤 / 三叉戟），且目标须为**玩家、敌对生物或 Boss** —— 与骰神赐福用的是同一道闸门，所以**远程击杀不会启动计时**。
- 计时**只启动一次、全程不重置**（后续命中不会续时）。
- 倒计时归零时移除效果，并**按原有口径连带移除**它给的一切（白泽赐福移除转化来的攻击力；降神移除施加者的攻击力 / 防御力加成）。
- 效果与计时是**两份独立状态**，「已生效但尚未开始计时」这一中间态按设计表现为**看起来是无限时长的图标**。

### 「敌对目标」再放宽一类：未驯服的羊驼 / 行商羊驼

- 此前的判定是「敌对生物 ∪ 中立生物（宠物除外）」，只排除**已驯服**的宠物。但**未驯服的**羊驼 / 行商羊驼这类生物虽然**可被驯服**，却是靠「被打后被激怒」反击的中立生物 —— **既没被驯服、也没被激怒，目标选择器就选不中它们**，与「只要会激怒就该算敌对」的直觉不符。
- 现按**能力口径**补上一类：**只要该生物会被激怒、且并非已驯服**，就纳入敌对目标。
- ⚠️ **实测影响面**：新增命中 **羊驼 / 行商羊驼**（原版同时满足「可驯服」与「会被激怒」的非宠物生物就是这两种）。
- 该判定是**全局**的：由前置模组 **StarEngine Lib** 统一实现，所以**所有**依赖它的效果一并生效 —— 骰神赐福的触发、法伤加成、目标选择器的可选中判定、电磁炮落雷选目标等。

### 美工刀 / 手电筒-强光：HUD 图标改为「跟随骰神赐福显示」

- 这三枚筹码的加成**本来就只在骰神赐福期间才会结算**，但它们的 HUD 状态图标此前并不跟随：**美工刀-初级 / 美工刀-锋利**在佩戴且生命 ≥ 60% 时会**一直**显示图标（哪怕当前没有任何可能生效的加成），**手电筒-强光**则**根本没有图标**。现在统一为「**非赐福状态即隐藏**」。
- **美工刀-初级 / 美工刀-锋利**：显示条件 = 佩戴对应筹码 **且** 生命 ≥ 60%（或处于汲取状态）**且** 当前处于骰神赐福状态；不在赐福状态即隐藏。
- **手电筒-强光**（**本次新增图标**）：显示条件 = 佩戴筹码 **且** 处于骰神赐福状态 **且** 星光达到 **4 点**（每 4 点星光 +1 点额外伤害，星光不足 4 时**无加伤、不显示**）。
- 图标复用各筹码自己的贴图，**不新增美术资源**。

### 手电筒-强光：星光改由「击杀」获得

- 获得星光的条件由「攻击单个敌对目标（同一目标仅一次）」改为「**击杀**不少于 **20 血**的敌对目标」，每次 **+1** 星光；判据与「诅咒之剑」一致（比对目标的**最大生命值**）。
- 「击杀」天然一次性，因此旧的 UUID 去重记录、以及「已记录目标满 256 个后不再发放」的隐性截断都随之取消。
- 「**每 4 层星光 +1 点攻击伤害**」的加伤机制**不变**。

### 美工刀：基础 +2 / +4 改回「攻击力」

- **美工刀-初级 / 美工刀-锋利**的加成现在是**两段不同性质**的：**基础 +2 / +4 直接增加攻击力**，而**「当前治愈层数」那一部分**才是额外结算的**攻击伤害**。
- 修正了此前把**基础 +2 / +4** 也一并算作「攻击伤害」的错误 —— 那样会让依赖「攻击力」的技能少算这 2 / 4 点。两段必须严格区分，因为它们影响的技能不同。
- 触发条件不变：生命值 ≥ 60%，或处于「汲取」状态。

### 卡牌品阶重排

- **攻击-中 / 大 / 特大**与**防御-中 / 大 / 特大**统一为**蓝色**（原为 白 / 蓝 / 紫）。
- **狂暴**、**以毒攻毒**、**你有我有**由**紫**下调为**蓝**。
- **王之力**由**金**下调为**紫**。
- 品阶只影响物品名字颜色与（金 / 传奇以上的）提示框描边：蓝色与紫色**不改变**描边样式。赏金奖励的兑换价值本轮**未作调整**。

## 🐛 问题修复

### 战利品箱概率修正：本模组物品此前被算了两遍

- 所有原版战利品箱都会同时滚「原版主表」与附加的本模组「星盘表」，而 **星币 / 空白筹码 / 星盘 / 玻璃骰子** 这四条池此前在**两张表上各注入了一次**，于是实际概率被整体抬高：
  - 星币 **5% → 9.75%**、空白筹码 **3% → 5.91%**、玻璃骰子 **2% → 3.96%**（均约为标称值的**两倍**）；星盘 **5.95% → 6.89%**。
- 现在附加表不再被重复注入 ⇒ 各池回到标称概率：**星币 5%、空白筹码 3%、玻璃骰子 2%、星盘 5.95%**（星盘 = 附加表的 5% + 主表的 1%）；**末地城**为星币 **9%**、星盘 **9.75%**、玻璃骰子 **5%**；**埋藏宝藏**的空白筹码仍是 **100%** 必出。

### 绿洲女王立牌卸下时：连同「女王特权」与临时牌一起清理

- 此前卸下立牌只清掉被动折算的护甲，**「女王特权」效果（HUD 倒计时）与全部临时牌都还留在身上**，最长可持续到效果的 **3:00** 自然到期 —— 与其它立牌「卸下即清理」的约定不一致。
- 现在卸下立牌的瞬间即**移除「女王特权」效果**并**清空全部临时牌**（物品栏、副手、已装配到骰子里的、以及打开的卡牌栏与光标上的），与主动技能自然到期、被外力移除、玩家死亡时的清理口径**完全一致**。

### 机械师立牌的「精准打击」现在看得见了

- 此前该效果被施加到怪物身上时**未开启粒子显示**，导致它在世界上**完全不可见** —— 你无法判断这次轨道轰炸有没有触发精准打击、目标身上已经叠了几层，观感上等同于「效果不存在 / 打完就消失了」。
- 现在命中目标会**持续飘出该效果的粒子**，层数越高越容易辨认。
- 效果的持续时间与「**永久保留直到目标死亡**」的设定**未受影响**（效果本身一直正常保留，只是此前没有任何视觉指示）。

## 📌 安装要求

- ✅ **前置模组 StarEngine Lib 仍随本模组内嵌 —— 你无需单独安装**：产物内自带一份 `starengine_lib`（内嵌于 `META-INF/jarjar/`），由加载器在启动时自动载入。
- ⚠️ **本版起内嵌库由 `1.0.4` 升到 `1.0.5`**：兼容区间随之变为 **`[1.0.5,2.0)`**。本版「敌对目标」判定放宽的实现在该库中，**库与模组必须成对更新**。
- ⚠️ **请不要再单独往 `mods` 放 `starengine_lib-*.jar`**：加载器按 modId 去重时**优先采用 `mods` 目录里那一份、丢弃内嵌副本** —— 若那份是更旧的版本（`1.0.4` 及更早），会盖掉本模组自带的新库（表现为前置版本不匹配，或「敌对目标」仍是旧判定）。**自 1.3.1 起无需再单独安装该库**，1.3.0 及更早才需要。
- 库的源码仓库：<https://github.com/merlin-kitsune/starengine_lib>
- **其它前置**：Curios API（**1.20.1 另外强制需要 Mixin Booster**）。
- **26.1.2 线**：前置 Curios API **15+**；该线**无 Iron's Spells 'n Spellbooks 联动**。
- **可选联动**：帕秋莉手册（规则书）、Bountiful 赏金板。
- **版本互通门槛（联机）**：客户端与服务端必须为**同一二号位版本**（`1.3.x` ↔ `1.3.y` 可互通）。跨版本连接会被**明确拒绝并给出提示**，而不是静默失败。
