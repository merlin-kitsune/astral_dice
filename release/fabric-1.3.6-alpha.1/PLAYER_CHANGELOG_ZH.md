# 星之骰戏 —— Fabric 1.20.1（移植线）

**版本 `1.3.6-alpha.1`** · alpha 渠道（预发布）· Minecraft 1.20.1 · Fabric

> ⚠️ **这是 Fabric 移植线，不是正式版。** 正式版面向 NeoForge 1.21.1 / Forge 1.20.1 / NeoForge 26.1.2。
> 本线使用**独立版本号**（`-alpha.N`，与 26.1.2 线的 `-beta.N` 同构）⇒ 永不占用正式版的版本号。

## 必需前置

- **Fabric Loader 0.19.5+**
- **Fabric API**（1.20.1 线，0.92.12）
- **StarEngine Lib —— 已内嵌，请勿另行安装。** 通过 Jar-in-Jar 内嵌（`1.0.6-alpha.1`）。
  若 mods 目录里仍有 `starengine_lib-*.jar`，请删除：散装文件优先级高于内嵌件，会被拿来顶替内嵌版本。
- **Puzzles Lib 8.1.33+**（事件桥；请连同它自己的前置 **Forge Config API Port 8.0.3** 一起装）
- **饰品栏提供者 —— Trinkets 3.7.2+ 或 Accessories 1.0.0-beta.48+ 二选一。** Fabric 的 `depends`
  是 AND 语义、无法表达「二选一」，因此两者都只声明为可选；模组在启动时自行检查，
  **只有两者都不在**才会拒绝启动。

可选：**Patchouli**（游戏内手册）。1.20.1 没有 Fabric 版 Bountiful，故本线没有赏金板。

## 本版更新

以下内容与三条正式线的 1.3.6 一致（本线是同一批改动的移植落地）。

### 平衡性调整与质量更新

- **没戴骰子时，你的立牌与筹码一律不再生效；重新戴上即恢复**：此前卸掉骰子只是「筹码栏不再刷新」，立牌与筹码的加成照旧生效 —— 等于不戴骰子白吃全部增益。现在补齐三条：
  - ① **没戴骰子时，立牌与筹码的一切功能一律不生效**（被动、主动技能、指定目标的技能、战斗数值、每刻运转的状态机全部停止），但**已经累计的数值不清零** —— 诅咒之剑攒下的攻击力、以及各立牌记下的层数都会保留。
  - ② **换装到「可用筹码栏更少」的骰子时当场收缩**：超出新上限的筹码会被取出并**退回你的物品栏**（不再等下一次对账）。
  - ③ **重生、或离开后重新进入时仍未佩戴骰子** ⇒ 强制恢复「没有筹码栏」的初始状态，并把筹码退回物品栏。
  - ⚠️ 面板上的加成会随「失效」一起消失，重新戴上骰子即恢复。
- **看板娘立牌的随机筹码：「池子补全」+「一次最多 1 个」**：
  - **池子**：此前是一份**手写清单**，只覆盖早期 41 种筹码，之后新增的 20 种（含紫色 / 金色飞星、充能类等）**一个都拿不到**。现改为**按当前全部筹码自动生成**，今后新增筹码自动进池，不会再有漏项。
  - **上限**：该被动是「主动技能累计返还 25 张战斗牌 → 获得 1 个随机筹码」，而主动技能会先把你物品栏里的牌全部收走 —— 牌多时一次返还能凑出好几个 25，**一口气刷出一堆筹码**。现在**每次主动至多产出 1 个**；超出 25 的部分仍会保留、留给下次继续累计，不会白扣。
- **电磁炮的雷击现在只有「你自己的近战攻击」能触发**：此前只要伤害的**直接来源**是你，就会登记雷击 —— 于是三种情况会误触发：**荆棘附魔等反伤**（反伤在系统里把你记为「攻击者」）、**你养的宠物攻击**（狼与女仆）、以及**法术 / 技能 / 远程**等非近战伤害。现在收紧为**只有你本人手持近战武器、亲手打出的攻击**才算。物品说明与手册中的「攻击敌对目标时」也同步改为「**近战**攻击敌对目标时」。
- **「千咒刻印」更名为「青之诅咒」，并从 JEI 与创造栏隐藏**：这个附魔是内部标记（唯一用途是让千咒卷轴把它计入 1 点诅咒），但原版会为每一个附魔自动生成一条「附魔书」条目放进创造栏，JEI 也跟着显示。现在它不再出现在创造栏与 JEI 里，物品提示中那行附魔名也一并抹掉。**只影响「看得见 / 拿得到」，功能不变**（诅咒计数照旧）。
- **青之诅咒的盔甲韧性削弱由 -100% 改为 -50%**：护甲值 -20% 不变，效果说明与物品提示同步更新。
- **筹码状态图标补齐，伤害增加型筹码的图标一律不再倒计时**：
  - ① **补上 5 枚此前完全没有图标的筹码** —— 磨刀石、肾上腺素（一般 / 高效各一个图标）、诅咒之剑、电流剑、电磁炮。
  - ② **伤害增加型筹码的状态一律「能生效就一直显示」**（不再显示几秒倒计时）：手电筒-强光与复仇之戟由 5 秒倒计时改为常驻（美工刀此前已是常驻）。
  - ③ 图标只在**加成真的生效**时亮：磨刀石与肾上腺素是「低血（≤50%）时」、诅咒之剑是「已攒到加成时」、电流剑是「充能 ≥ 4」、电磁炮是「充能 ≥ 6」。
  - ④ 顺带修掉一个隐患：卸下骰子后这些图标**会正常熄灭**（此前会残留成「功能已关、图标还在」）。

### BUG修复

- **修复医疗箱筹码「装备后不触发治愈、重生后也不触发」**：两个医疗箱（紧急 / 完备）此前只有在**骰神赐福开始**时才补给治愈层数，于是刚戴上时不生效，重生 / 重新登录 / 切换维度后同样不生效。现在**装备时**与**重生 / 重新登录 / 切换维度后**都会立刻触发一次治愈；卸下时会按账本把「本次装备补上的层数」扣回，靠反复重登刷层数的漏洞一并堵上。
- **修复史诗物品的提示框边框显示「上一个悬停物品」的颜色**：整合包里同时装了会改写提示框的模组时，史诗物品的边框会残留上一个物品的颜色（实测表现为金色）。现在史诗也**显式写入自己的档位色**；同时针对第三方提示框模组的颜色缓存加了缓解措施，并把「使用该模组时」的史诗边框一并校正为原版史诗色。
- **修复诅咒之剑攒下的攻击力加成会被死亡清空**：该加成记在玩家身上，死亡时筹码掉落会把它清零 —— 一次死亡就白攒。现在改为**死亡不清**，只有**真正把筹码卸下来**才清除。

- 此外还修复了大量描述与实际不符的问题。
