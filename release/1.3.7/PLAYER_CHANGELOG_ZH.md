# 星之骰戏 (Astral Dice) 1.3.7 更新日志

已发布：1.3.7 —— 本次是**内容调整与问题修复**版本，不含新增物品。调整方面：① 可对他人使用的治疗 / 功能效果牌改为可指定非敌对生物；② 奢华大餐对亡灵改为造成伤害；③ 骰神赐福的近战武器判定改回「黑名单」；④ 两口「饕餮之锅」纳入可触发；⑤ 效果牌的可选中生物扩大到未驯服的可驯服生物；⑥ 枪械本体不再计为近战；⑦ 事件效果改为「队伍 + 64 格」广播；⑧ 未装备充能筹码时隐藏充能图标；⑨ 探天卫星改为「效果牌目标选择距离 +50%」；⑩ 调查员立牌主动追加「书页射程」。修复方面：① 两处军火伤害被误判为远程 / 魔法伤害；② 激光与爆炸类伤害补入判定；③ 活体书页无法堆叠；④ 动作栏文本与物品名提示重叠；⑤ 动作栏两项配置移出配置文件；⑥ 配置文件版本号不更新；⑦ 死亡点遗留无法拾取的灵魂水晶；⑧ 效果牌会话吞按键 / 抢按键。

注意！前置模组 StarEngine Lib 已内嵌进本模组（内嵌 1.0.11），玩家无需再单独安装。如果你的 mods 目录里还放着手动下载的 starengine_lib-*.jar，请删掉它 —— 旧文件会盖掉内嵌的新版库。
注意！1.20.1 的 Mixin 运行时：**Mixin Booster ≥0.1.3** 或 **Sinytra Connector**，**二选一**即可（自 1.3.2-hotfix 起；此前为强制 Mixin Booster）。

## 内容与平衡性调整

- **「可对他人使用」的治疗 / 功能效果牌现在可指定「非敌对生物」**：**狂暴**、**奢华大餐**、**加急加快**三张牌的目标选择器此前只能指定玩家，现在可以指定 **16 格内的非敌对生物** —— 玩家、已驯服的宠物（狼 / 猫 / 鹦鹉）、被动家畜、村民，以及**未驯服的狼 / 铁傀儡 / 北极熊 / 蜜蜂等中立生物**。⚠️ **只有原版敌对生物不可选**（僵尸 / 骷髅 / 掠夺者 / 末影人 / 猪灵 …）。⚠️ 仍然可以按下鼠标右键对自身使用。⚠️ 对生物使用时目标会**正常吃到效果**（顺带修复了「对生物使用整张牌空放」）。
- **奢华大餐对亡灵生物改为造成伤害**：该牌现在与**原版治疗药水**一致 —— 受治疗目标若是**亡灵生物**（僵尸 / 骷髅 / 凋灵 / 幻翼 等），改为对其造成**等量魔法伤害**而非治疗。⚠️ **与阵营无关**：已驯服的亡灵宠物、队伍里的亡灵玩家同样受伤。
- **骰神赐福的「近战武器攻击」判定改回「黑名单」**：此前一度改为「按武器 / 工具物品标签的白名单」，那个口径会把**不把自己的武器加进原版标签的模组**（自带武器体系的那类）整类漏掉。现按裁决回退为黑名单：只排除**空手 / 盾牌 / 远程专用物品（弓 / 弩 / 弹弓）/ 方块 / 枪械类武器本体 / 非武器工具（剪刀 / 钓竿 / 打火石 / 刷子）**，其余一律计入 —— **包括全部挖掘工具（镐 / 锹 / 锄 / 斧）与各模组的武器**。⚠️ **同时具备近战与远程的武器不排除**（例：三叉戟）。
- **两口「饕餮之锅」现在可以触发骰神赐福**：两个联动模组各有一口按武器使用的「锅」—— 前者**不在任何物品标签里**，后者**同时是可放置的方块**（会被「方块不算近战」那条排除）⇒ 两者均已**点名纳入**，持其近战攻击照常触发骰神赐福。⚠️ 判定按注册名匹配，未安装对应模组的版本不受影响。
- **效果牌的可选中生物扩大到「未驯服的可驯服生物」**：活体书页与伤害效果牌（含符卡-祸）此前只能指定**敌对目标**。现改用**效果牌专用口径**，在原有集合之上增加「**未驯服**的可驯服生物」—— 狼 / 猫 / 鹦鹉，以及无主的马 / 驴 / 骡 / 骆驼 / 羊驼。⚠️ **已驯服的宠物与已被认领的坐骑仍不可选**；**村民 / 流浪商人一律排除**；⚠️ **立牌选择器（枪匠 / 大侦探 / 占星师…）与法伤判定等口径完全不变**。
- **枪械类武器本体不再能用于近战砸击**：持有现代枪械 / 射击对战类、蒸汽朋克军火与转轮机枪类、近代战场模拟类武器，以及某大型联动模组**内置子模组**中的枪械时，一律不计为近战武器攻击。⚠️ 该联动模组**本体**的物品不整段排除（其本体既含枪械、也含整套近战武器），只有其中的枪械本体被点名。
- **事件效果改为「队伍 + 64 格」广播**：大侦探立牌主动抽到的随机事件效果、以及「隐匿调查」阶段事件（隐匿 + 调查增益），此前只作用于触发者（真相揭露阶段才额外覆盖队友，且必须先满足「附近有 boss」才有 32 格范围）。现统一为：触发者**已加入队伍** ⇒ 作用于**全体队友** ∪ 触发者 **64 格内**的其他玩家；触发者**无任何队伍** ⇒ 作用于**所有无队伍玩家** ∪ 触发者 **64 格内所有玩家**。事件触发的立牌被动（大侦探 +3 星币 / 调查员活体书页）同步按该目标集合发放。⚠️ 大侦探的**负面**结果（中毒 / 凋灵 / 黑暗 / 虚弱 / 瞬间伤害等）同样按上述范围广播。
- **未装备充能筹码时隐藏充能状态图标**：玩家身上有充能状态、但饰品栏**没有**任何充能类筹码（飞行引擎 / 能量回收器 / 电流剑 / 高级外设 / 永动机 / 电流核心 / 电击手套 / 安全气囊 / 电磁炮 / 原初核心，共 10 枚）时，HUD 不再显示「充能」图标；装备回任一充能筹码后立即恢复。
- **探天卫星改口径：「击杀返还随机效果牌」→「效果牌的目标选择距离 +50%」**：探天卫星筹码**不再**在「轨道炮生效期间以远程 / 魔法击杀敌方目标」时返还随机效果牌；改为**佩戴即生效的常驻加成** —— 手持任意**效果牌**时，其目标选择器的锁定范围 **+50%**（16 格 → 24 格）。⚠️ 只作用于**效果牌**，**立牌主动技能的选择器不受影响**；⚠️ 与调查员立牌主动的「书页射程」**相加**，合计上限 **64 格**。
- **调查员立牌主动追加「书页射程」**：调查员立牌（rin）的主动技能「活体书页」在原有的「获得 1～2 张活体书页」之外，**追加**一个 **2:00** 的状态「书页射程」—— 持有期间**活体书页的使用射程 +50%**（32 格 → 48 格；若同时佩戴探天卫星筹码则 32 格 → **64 格**）。⚠️ 状态**可见**（HUD 图标 + 悬停说明），自然到期即消失；重复施放只**刷新时长**、不叠加倍率。⚠️ 主动技能原有的冷却节奏与「生效中」锁定口径**不变**。

## BUG修复

- **修复：两处军火伤害被误判为远程 / 魔法伤害**：用于屏蔽军火伤害的判定此前只认伤害标识 / 弹丸类名里的关键词，实测有两处漏判 —— ① 某军火模组的**左轮全家族**：其弹丸继承原版箭矢基类（因此落进了远程 / 魔法伤害的判定范围），而伤害标识里**没有任何关键词**；② 另一军火模组的**霰弹**：弹丸同样落在判据范围内，伤害标识也不含关键词。二者此前都会被**当成远程 / 魔法伤害**吃满加成。现改为按**逐条取自实物的证据表**判定：先比精确伤害类型、再比军火弹丸来源，最后才是关键词兜底（只服务未纳入分析表的模组）。
- **军火判定补入「激光武器」与「爆炸类伤害」**：上一条的证据表原本只覆盖枪弹 / 炮弹通道，现补入某战场模拟模组的 **3 个激光武器伤害类型**与 **5 个爆炸类伤害类型**（弹丸爆炸 / 自定义爆炸 / 载具爆炸 / 地雷 / 跳雷）—— 它们的弹丸与爆炸装置同样落在远程 / 魔法伤害的判定范围内，不排除就会被当成远程 / 魔法伤害吃加成。
- **修复活体书页「无法堆叠」**：此前 6 条产生路径各自构造物品，其中「魔法箭袋」返还漏绑了专属牌的「获得者」信息 ⇒ 同一玩家手里会同时存在「有获得者 / 无获得者」两种形态，而堆叠判定是逐项比较 ⇒ 同物品**不可堆叠**。现新增两个**唯一入口**（统一发放与统一复制 / 返还），两条发放路径与三条复制路径全部改走入口，杜绝漏绑。
- **修复动作栏文本与物品名称提示重叠 + 淡出时长压缩**：动作栏文本基线此前与原版 hotbar 物品名提示**仅差 1px**（且后者随护甲 / 血量行上移），同时出现时同一行互相压盖。现改为与原版动作栏同高，二者至少相隔 9px；淡出时长同时由 1 秒压缩为 **0.5 秒**。
- **动作栏两项移出配置文件**（配套上一条）：动作栏时长与淡出时长不再写入配置文件 —— **所有玩家强制使用新的固定值**（旧配置里的对应段会被自动清除），避免「只改默认值对已安装玩家无效」。
- **修复配置文件版本号不会更新**：此前检测到旧版本只做备份、**不回写文件里的版本号**，而框架对「已存在且校验通过」的键原样保留 ⇒ 版本号永远停在旧值、且**每次启动重复备份**一份内容相同的文件。现备份后把版本号显式写回，使「一个版本号 = 一次迁移」成立。
- **修复死亡点会永久留一枚无法拾取的水晶**：该修正本应在「佩戴该联动模组的诅咒饰品 + 身上有「弱点识破」层数」的玩家死亡时，把被撕下的灵魂水晶一并收回。但回收用的是**原版掉落物类型**筛选，而该模组的水晶载体是它**自己的实体**（基类不是原版掉落物）⇒ 筛选永远命中不到、回收**静默失效**；又因为最大生命值已还原，水晶自带的「回收灵魂」逻辑认定**无可回收之物** ⇒ **连水晶主人也捡不起来**。现改为按该模组的载体实体精确检索，并把回收提前到**死亡当刻起每 tick**（不再依赖玩家重生），同时以「主人 + 持有物 + 新建时间」三重限定，既不误伤该玩家早先留下的合法水晶，也不触碰该模组另一分支掉出的存储水晶。
- **修复效果牌会话「吞按键 / 抢按键」**：手持选择器类效果牌（主手一持就自动开启目标选择器）时，模组此前**关掉 / 接管了远超需要的输入** —— ① 主动技能键 J 被直接转发给立牌主动技能，而「先开会话、确认后才施效」的技能路径会把手里的**效果牌选择器顶掉**；② 鼠标**中键 / 侧键**被随左键一起取消（连「选取方块」都不可用）；③ 卡牌栏键 H 被吞掉，而这类会话**本来就不因开界面而取消**（看背包 / 按 ESC 都不退出选择），两者自相矛盾。现按裁决把这类会话的输入**收口为「释放键 + 收起键」**：**左键 = 释放（确认目标）**；**右键 = 对自身使用 / 收起** —— 只能对目标释放的主动技能（占星师 / 秘密侦探 / 枪匠 / 商人 / 教主等立牌动作，以及「你有我有」/「活体书页」/「符卡-祸」）**右键改为直接取消选择**（旧行为只弹一句「该技能无法对自己使用」并保留会话）；**下蹲 + 右键 = 收起**；**主动技能键 J = 收起**（不再穿透成立牌主动技能）。其余输入**一律放行**：**鼠标中键 / 侧键**、**卡牌栏键 H**（手持效果牌时也能打开卡牌栏）。⚠️ **收起不是禁用**：收起后服务端会记住「这张牌仍在主手」⇒ 选择器**不会**在下一 tick 自动弹回来；把牌移出主手再握回来即可重新开局，而 J 也会随之恢复为「施放立牌主动技能」。
