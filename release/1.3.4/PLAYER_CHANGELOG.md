# Astral Dice 1.3.4 Changelog

Released: 1.3.4 — a **bug-fix** release with no new items. Four classes of problems are fixed: King's Power's self-damage cost often did nothing at all in combat; the Sweeper Sign lost part of its attack/defense bonus on death; permanent effects were displayed as a countdown of tens of thousands of hours; and status effect descriptions were invisible in game.

Note! The prerequisite mod StarEngine Lib is bundled inside this mod (embedded 1.0.5) — you no longer need to install it separately. If your mods folder still contains a manually downloaded starengine_lib-*.jar, delete it: the old file would override the embedded one.
Note! On 1.20.1 the Mixin runtime can be **Mixin Booster ≥0.1.3** **or** **Sinytra Connector** — pick either one (since 1.3.2-hotfix; previously Mixin Booster was mandatory).

## Bug Fixes

- **King's Power's 8-point self-damage cost often did nothing at all in combat — it now always lands**: the cost used to go through ordinary dice damage, which obeys the vanilla invulnerability window, so right after being hit by a mob (or on a second King's Power in a row) the damage was swallowed whole: **the stacks went up while the health bar did not move**, making the cost purely cosmetic (creative mode negated it entirely). It now goes through a dedicated "**card cost**" damage type and **settles even inside the invulnerability window**. That type **still respects armor / resistance / protection** (a cost is not true damage and does not pierce defense), exactly as before.
- **The Sweeper Sign no longer loses part of its attack / defense bonus on death**: both bonuses are stored on the sign item itself, and a cleanup step used to zero them on death — so dropping the sign and picking it back up cost you a chunk. They are now **kept on death** (same stance as the Ninja, Investigator and Mamushi Signs): both the death drop and the respawn pickup preserve them fully, and **only genuinely unequipping the sign clears them**. The equivalent reset on the Padman Sign is unchanged.
- **Every "permanent" effect no longer shows a countdown of tens of thousands of hours — they all display ∞**: previously only Precision Strike used the vanilla "truly infinite" duration; the other 8 permanent effects (**Charge, Doll Crafting, Doll Complete, Fox Light, True Dragon Form, Misfortune, Reasoning Time, Weakness Insight**) plus the application sites for Blue Curse and Undercover Investigation wrote a huge number instead, so the HUD and the inventory effect panel showed a remaining time of several hundred thousand hours. The Magic Tome's play-count effect was the most specific case — it has no timer by design, yet it carried a countdown of about **8:20**. All of them now use the vanilla infinite duration and display as **∞**.
- **Status effect "notes" (the description text) are now visible in game**: the language files already carried 21 effect descriptions (Berserk, Concealment, Empower, Reasoning Time, Baize's Blessing, ...), but **there was no rendering path at all** — only the three effect-card **items** (Berserk, Unwavering, Fight Poison with Poison) showed them, on their item tooltips, so hovering the **status effect itself** showed nothing but "name + remaining time". Both NeoForge lines now hook the effect panel's tooltips through the official API, and 1.20.1 does the same through a Mixin. All three lines share one rule: a grey description line is appended **only when the matching language text actually exists**, so effects without a description get no extra blank line.
- Plus a batch of wording and handbook corrections.
