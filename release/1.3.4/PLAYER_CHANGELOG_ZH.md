# 星之骰戏 (Astral Dice) 1.3.4 更新日志

已发布：1.3.4 —— 本次是**问题修复**版本，不含新增物品。修掉了四类问题：「王之力」的自伤代价在战斗中常常完全不生效；扫地机立牌的攻/防加成在死亡时会掉一部分；常驻效果被显示成几万小时的倒计时；以及状态效果的描述文本在游戏里一直看不到。

注意！前置模组 StarEngine Lib 已内嵌进本模组（内嵌 1.0.5），玩家无需再单独安装。如果你的 mods 目录里还放着手动下载的 starengine_lib-*.jar，请删掉它 —— 旧文件会盖掉内嵌的新版库。
注意！1.20.1 的 Mixin 运行时：**Mixin Booster ≥0.1.3** 或 **Sinytra Connector**，**二选一**即可（自 1.3.2-hotfix 起；此前为强制 Mixin Booster）。

## BUG修复

- **「王之力」的 8 点自伤代价在战斗中经常完全不生效，现在每次使用必定扣血**：此前这 8 点走的是普通骰子伤害，会受原版「受击无敌帧」约束 —— 刚被怪物打过、或连续使用「王之力」时，伤害被整段吞掉：**层数照加，血条不动**，代价形同虚设（创造模式下更是完全免疫）。现在改用一条独立的「**卡牌代价**」伤害类型，**无敌帧内照常结算**。该类型**仍受护甲 / 抗性 / 保护减免**（代价不是真伤，不穿透防御），与之前一致。
- **扫地机立牌的攻击力 / 防御力加成不再因为死亡而掉一部分**：这两个加成记录在立牌物品自身的数据上，此前死亡时会有一段清理逻辑把它们清零 ⇒ 死亡掉落再捡回来就少一截。现按**死亡保留**处理（与忍者、调查员、蛟龙三个立牌同口径）—— 掉落与重生拾回都完整保留，**只有真正卸下立牌才会清零**。上班族立牌的同类清零保持不变。
- **所有「常驻」效果不再显示成几万小时的倒计时，统一显示为 ∞**：此前只有「精准打击」用了原版「真·无限时长」，其余 8 个常驻效果（**充能 / 人偶制作 / 人偶完成 / 狐光 / 真龙形态 / 厄运 / 推理时间 / 弱点识破**）以及青之诅咒、隐匿调查的施加处写的是一个极大数值，于是 HUD 与物品栏效果面板上一直显示一个几十万小时的剩余时间；「魔法秘典」的出牌计数效果更具体 —— 它本来没有时长概念，却带着一个约 **8:20** 的倒计时。现全部改用原版无限时长，一律显示为 **∞**。
- **状态效果的「注释」（描述文本）现在能在游戏里看到了**：语言文件里其实早已写好 21 条效果描述（狂暴 / 隐匿 / 赋能 / 推理时间 / 白泽赐福 等），但**此前没有任何渲染通道** —— 只有狂暴、岿然不动、以毒攻毒这三张效果牌的**物品 tooltip** 会显示描述，而把鼠标悬停在**状态效果本身**上时只能看到「效果名 + 剩余时长」。现在两个 NeoForge 版本线用官方接口挂上了效果面板的提示，1.20.1 用 Mixin 实现了同样的效果。三个版本线口径一致：**只在对应语言确实有描述时**才追加一行灰色说明，没写描述的效果不会多出一行空白。
- 此外还同步修正了一批文案与手册描述。
