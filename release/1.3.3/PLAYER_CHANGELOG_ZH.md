# 星之骰戏 (Astral Dice) 1.3.3 更新日志

已发布：1.3.3 —— 本次是**平衡性调整与问题修复**版本，不含新增物品。主要是四件事：① 四项「受击类」效果不再能被环境伤害与自伤刷取；② 风水师 / 教主 / 秘密侦探三块立牌的技能口径调整；③ 动作栏的染色断层与文本丢失修复；④ 一批文案与手册描述修正。

注意！前置模组 StarEngine Lib 已内嵌进本模组（内嵌 1.0.5），玩家无需再单独安装。如果你的 mods 目录里还放着手动下载的 starengine_lib-*.jar，请删掉它 —— 旧文件会盖掉内嵌的新版库。
注意！1.20.1 的 Mixin 运行时：**Mixin Booster ≥0.1.3** 或 **Sinytra Connector**，**二选一**即可（自 1.3.2-hotfix 起；此前为强制 Mixin Booster）。

## 平衡性调整与质量更新

- **风水师立牌「完美帮手」改为把「养精蓄锐」直接拉满**：对装备「大当家立牌」的玩家施加「白泽赐福」时，不再只 +1 层，而是把该玩家的「养精蓄锐」**直接补满到上限 5 层**。
- **教主立牌「降神」的狐光追加改为「追击」额外伤害**：获得「降神」的玩家攻击敌对目标时触发「追击」，本次攻击**额外造成**（施加者自身攻击力快照 + 当前「狐光」层数）的伤害。
  - 这份加伤**不再计入攻击力**，改为命中落地后单独结算 —— 因此**不再受目标防御力抵扣**，也不再参与「全力攻击」等既有倍率。此前它是加进攻击力的；顺带消除了「打开卡牌栏查看攻击力」会误消耗「狐光」的隐患。
  - **消耗规则不变**：仍只在攻击**新目标**时消耗 1 层「狐光」，同一目标的后续攻击照常触发追击且不再消耗；攻击新目标时若「狐光」已为 0，本次不追加。
- **秘密侦探立牌「调查阶段」：原「隐身」整体替换为新效果「隐匿」**：持有期间**生物无法把你设为索敌目标**（只看这个效果，不再要求原版隐身）；你一旦对**怪物**造成有效伤害（近战 / 远程 / 法术，任意攻击方式都算）⇒ **立即解除「隐匿」**，并在**骰战中追加目标身上「标记」层数的伤害**，**持续到「调查阶段」增益结束**。四个阶段的时长**统一为 1:00**（原 I / II / III 分别为 0:15 / 0:20 / 0:30）。新效果沿用原版隐身图标。
- **「命运的指引」新增能力：激活期间战斗骰点恒为 6**：与上班族立牌的「下次必 6」同口径 —— **未装备骰子时仍恒为 0**。tooltip 的能力清单同步改版（编号 `1./2./3./4.` 统一改为短横杠，并在第 2 条之后插入该新条目）。
- **风水师「白泽赐福」/ 教主「降神」的倒计时启动条件扩为「任意攻击命中」**：这两个效果的 2:00 倒计时此前要求「近战武器攻击」才启动，现在**近战或远程**（箭 / 投掷物 / 法术等由你造成的伤害）**只要有效命中目标**即可启动 —— 必须是**有效命中**（伤害真正落地），且目标仍须是骰神赐福的合法目标。计时仍**只启动一次、全程不重置**。
- **史莱姆立牌：移除主动技能的范围治疗**：删除「以其为中心，对周围 16 格内的玩家 / 宠物 / 可骑乘生物施加瞬间治疗」这一整段。范围部分现在只剩「对范围内敌对生物施加缓慢 (1:00)」；主体效果（目标 +3 治愈 + 瞬间治疗）不变。
- **大碗炖肉：移除友方生物治疗，并把治愈点提到 2**：赐福结束时**不再治疗友方生物**；治愈点由 **1 改为 2**，作用对象明确写为**「使自身和 16 格范围内所有友方玩家」**。
- **文案清理**：枪匠「破绽」的主动与被动中重复出现的「会被枪匠闪避；闪避后自动触发反击并获得弱点识破层数加成」统一改写为**「会被自身闪避并触发反击」**（机制未变）；「岿然不动」的效果说明前半由「每层护甲 +8（对应骰战防御力 +4）」直接改为**「防御力 +4」**（只改文案，底层属性修饰未变）；蓄力牌删除多余的「（须在赐福前放入卡牌栏）」括注。

## BUG修复

- **修复动作栏的文案染色与文本丢失**：
  - **文本丢失**：秘密侦探立牌「隐匿行动」与占星师立牌「虚弱印记」两条成功提示所引用的语言键在三个版本上全部缺失，确认目标后动作栏显示的是一串裸键而不是句子；现已补齐中英日三语。
  - **染色断层**：11 条动作栏文案内部自带色码，而发送端统一按黄色着色，于是出现「**前半黄、后半灰**」的断层（人偶师 / 风水师 / 怪力侦探 / 教主 / 蛟龙 / 鼠鼠救我 等）。现已清除全部内嵌色码，整条颜色由外层统一控制。
  - **配色不统一**：按「拒绝 / 阻止类提示必须为红色」的口径，把 11 条此前仍是黄色的拒绝类提示（忍者立牌三条「未释放」、绿洲女王临时牌上限 / 空位不足、经商立牌无可兑换星光、怪力侦探地面受阻 / 无目标、人偶师末影珍珠被禁、教主降神生效中、蛟龙强制冷却）改为**红色**；「电流核心」拆分为拒绝时红（充能不足）/ 成功时黄（冷却立即完成）；「蛟龙强制冷却」三个版本线此前的颜色互不相同，现统一为红。
  - **两条并行通道合并**：安全气囊触发、钱包存取反馈、卡牌栏「需要佩戴骰子」、客户端「本轮出牌数已用完」四处此前走的是原版覆盖层（白色，位置与其余提示不同），而其余约 60 处走模组自己的动作栏 —— 同一条 UI 由两套系统渲染；现已统一到模组动作栏并着色（安全气囊 / 钱包为黄，「需要佩戴骰子」/「出牌数已用完」为红）。
- **四个「受击类」效果不再能被环境伤害与自伤触发，现收紧为「只有敌对目标的攻击才算」**：
  这四者的原判据是「玩家受到**任何**伤害」，于是摔落 / 仙人掌 / 着火 / 溺水 / 饥饿等**环境伤害**，以及本模组「符卡-祸」每 2:00 对持有者的自身真伤（伤害源**没有实体**、不构成任何人的攻击）与玩家自伤，全都能触发它们 —— 玩家完全不接触敌人即可白拿收益（星币不设上限，等于可刷）：
  - **缓冲盾牌**（治愈流派筹码）：受击的 +2 治愈 / +3 星币；
  - **鼠鼠护盾**的「反击」：被任意生物攻击都会消耗 1 层反击 —— 队友玩家、已驯服的宠物、未激怒的中立生物的攻击同样消耗，且反击会打在友军身上；
  - **史莱姆立牌**「细胞分裂」：受击的 +1 层治愈与主动技能 −10 秒冷却；
  - **吸血鬼立牌**「汲取」（受伤一侧）：按本次伤害一半回血。
  现四者统一收紧为**只有敌对目标的攻击**才触发，三条判据缺一不可：存在**实际攻击者**（排除环境伤害与无来源真伤）、攻击者不是自己、攻击者对你构成**敌对目标**（敌对生物、中立生物（宠物除外）、被激怒的可驯养动物，以及「非同队伍且曾主动攻击过你的玩家」）。后三者的说明文案与手册条目一并同步。
  ⚠️ **人偶师立牌「魔女漂浮」不在此列**：其文案本就写明「**任何**对你的近战攻击都会被闪避」，经确认属**特性**、维持不变。
- 此外还同步修正了一批文案与手册描述。
